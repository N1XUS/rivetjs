# Public agent skill bundles

`rivet-*/` is generated from `libs/mcp/ai/skills/<id>.md` plus optional `skills/<id>/` resources and the root MIT LICENSE. Do not edit generated bundles. Run `node libs/mcp/ai/sync.ts [--check]`; the generator owns all files under the public `rivet-*` bundle namespace and removes obsolete resources. `README.md` documents consumer installation and distribution. Source/generator invariants are in `libs/mcp/ai/CLAUDE.md`.
