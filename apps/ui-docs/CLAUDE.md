## Layout
- Scheduler context-menu review correction (2026-10-23): creation and duplication share a serializable monotonic `nextId` signal, independent of event-array length after deletion. The permanent production manifest repeats duplicate/delete/duplicate and new/delete/new, then independently renames/removes retained events to catch identity aliasing.

Initial-range loader and full props/event/keyboard/live-vs-read-once tables; attribution on `start/licenses` linked by component note. API entry `@rivetjs/ui/scheduler`; generated only via docs-kit. Current-time demo/test chooses Today so a static build stays useful; its current-time line wording follows the theme rather than naming a fixed color.
- Published alpha docs: version labels and StackBlitz package specs use `0.1.0-alpha.1`; installation guides use public npm packages. Production hosting is enabled at `ui.rivetjs.severyn.pro` (UI uses the two-Worker Free setup).
- Free-tier hosting split: `scripts/docs-cloudflare.ts` preserves the checked `dist/client` and copies pages to `dist/cloudflare/site`, `/assets/*` + `/pagefind/*` to `dist/cloudflare/assets` (each ≤20,000 files, same URLs/bytes, `_headers` copied to both). `wrangler.assets.jsonc` binds `rivetjs-ui-assets` to those two routes in front of the custom-domain `rivetjs-ui`. Cloudflare deploy command: `npm run docs:deploy:ui:cloudflare` (assets then pages; secondary assets command clears only the one-Worker CI identity hint).

## Examples

- Steps: CSS selectors only. Inside a ToggleButtonGroup a ToggleButton `id` is the selection key, not the DOM id (select by `aria-label` / `:nth-child`). Inside a cdk field, an `id` on `Label` breaks the input's `aria-labelledby` (leave the label id to the field).
- No `<style>` JSX (RV1007): demo CSS goes in the example's `src/styles.css` (shown as a second file). SVG attributes kebab-case. Shared JSX constants → factories (JSX is eager). Spreading props onto another tag: type the render function `(props: Record<string, any>)`.

- A console error (incl. a failed image load) fails the example check (the docs build).
