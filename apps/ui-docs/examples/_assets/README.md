# Shared example images (apps/ui-docs)

Rivet-generated stand-ins for the images HeroUI's demos load from its own CDN. Each depicts the same idea as the upstream image (person avatars = portraits of distinct fictional people, one file per upstream `u=` id, shared across examples) (subject, framing, palette, aspect ratio); no upstream pixels are used. Generated 2026-10-08 with `codex exec` (headless, one call per image), reviewed by hand, then resized / re-encoded with sharp (JPEG q82 mozjpeg, PNG palette). The QR code is a real one (encodes `https://rivetjs.dev`), written by a standard-library Python encoder codex produced; verified with macOS CoreImage.

Usage: an example imports `../assets/<file>?image` from `src/routes/index.tsx`; docs-kit copies the file into the example's `src/assets/` (see `libs/docs-kit/CLAUDE.md` "Shared example assets"). New image: add the file + a row here.

Prompt template: `Generate one image, <size> (or the closest size you support with the same orientation): <prompt>. Style: Natural and understated, realistic colours, soft natural light, no glossy AI-art look, no lens flare, no bokeh effects beyond what is described, no text, no letters, no logos, no watermarks, no brands. Save it as ./<file> in the current directory (convert/resize with sips if needed) and print the absolute path. Do nothing else.`
