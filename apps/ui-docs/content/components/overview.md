Each component is its own subpath: `import { Button } from "@rivetjs/ui/button"`. Compound components usually expose a `.Root` alias and named part exports (`CardHeader`, …). Some exports are single components or parts objects; check each page’s anatomy and API reference. The tables below link every component subpath in this package.
