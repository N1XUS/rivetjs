# apps/docs
> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Main Rivet docs site (framework: reactivity, runtime, router, compiler, i18n, tooling), built on `@rivetjs/docs-kit`. Engine internals: [libs/docs-kit/CLAUDE.md](../../libs/docs-kit/CLAUDE.md). The cdk site `apps/cdk-docs` has the same structure.

## Layout
- npm release: all site versions and StackBlitz dependency specs use `0.1.0-alpha.1`; setup/tooling guides describe public npm installs. Home command badges show the published alpha version. Main navbar UI goes to `site.sites.ui`; Guide keeps only UI package overview and Kit. The obsolete component pages and port preview are removed; `public/_redirects` sends their URLs to the dedicated UI docs.
- Homepage (2026-10-24): Runtime Studio replaces the 2026-10-11 landing page. The previous CSS-only hero, likes/download readout, Select showcase and measured footer remain as unused legacy helpers; their historical performance figures do not describe the new homepage.
- Browser style parity waits for `document.fonts.ready` (first-visit font swapping); the reduced-motion assertion waits for the deferred sheets' 0.01ms transitions to finish before requiring zero animations.
- `wrangler.jsonc`: production static assets from `dist/client`, Worker `rivetjs`, custom domain `rivetjs.severyn.pro`. Cloudflare repo-root build: `npm run docs:build:cloudflare -- apps/docs`; deploy with `--config apps/docs/wrangler.jsonc`. Production origins and sibling links are set by that script; source links use `N1XUS/rivetjs`.
- `site.config.ts`: name, origin (docs `:4321`; env `DOCS_ORIGIN`; production builds set it, canonical URLs use `origin`; examples are pages of this app (`/examples/<id>/frame/`, docs-kit "Example frames"), live in iframes on the same origin), `sites` (`cdk` → `CDK_DOCS_ORIGIN`, `ui` → `UI_DOCS_ORIGIN` (apps/ui-docs, `:4327`), for `[x](site:cdk/…)` / `site:ui/…` links), repo, version, `leanPages: ["/"]` (home: generic idle highlighter/search shortcut and router fetch-ahead disabled; page-owned visible effects still start).

## Pages (content/*.md)
- Frontmatter: `title`, `description` (≤160 chars), `template` (`guide`, `concept`, `recipe`, `best-practice`, `gotcha`, `reference`, `tutorial`, `page`, `home`, `stub`), `status`, `since`, `tags`, `related: [section/page, …]`.
- Every page appears exactly once in `_nav.ts`, as a page or a page's `children` (build fails on orphans/duplicates).
- Links: relative `.md` links between pages. Directives: `::example{id=…}`, `::chart{id=…}` (`content/_charts.ts`), `::api{symbol="@rivetjs/pkg/entry#name"}`, `::starter{…}`, `:term[…]`, `:kbd[…]`; callouts `:::note|tip|warning|gotcha`; fence meta `compiled` (tsx/jsx: real dom + server compiler output behind a switch, e.g. `learn/signals.md` Cart). No raw HTML. Full list: [libs/docs-kit/tools/content/CLAUDE.md](../../libs/docs-kit/tools/content/CLAUDE.md).
- `TODO-CONTENT` marks placeholder pages (`check-content --strict` fails on them).
- Plain language: say what the reader can do after the page; document only what the code does. Behaviour claims (resume, live props, serializability) are verified by a compile / render probe before they land; known runtime gaps go in a `:::gotcha`, not silently omitted.

## Examples (examples/<id>/)
- Files: `example.ts` (`export default defineExample({...})` from `@rivetjs/docs-kit/define.ts`), `src/routes/**.tsx`, `src/styles.css`, optional `src/components/*.tsx` (auto-listed as resume modules), optional server files. Merged over `templates/starter-static` (or `starter-server` with `mode: "server"`).
- `defineExample`: `title`, `summary`, `tags`, `status`, `mode`, `frame: { height, auto?, width?, theme? }` (`auto`: frame follows its content height; [libs/docs-kit/CLAUDE.md](../../libs/docs-kit/CLAUDE.md) "Frame height"), `show: [files]`, `test: Step[]`. `Step` schema: [libs/docs-kit/CLAUDE.md](../../libs/docs-kit/CLAUDE.md#example-step-schema-definets-runner-toolsexamplests-run).
- `test` steps run in Chromium on a production build; a failing step or console error FAILS the build.
- `// #region demo` / `// #endregion` marks the focused code. Callbacks: inline arrows or local consts (resumable).
- `src/generated/examples.json` is what `<Example>` reads (server only, from disk); `docs-kit examples apps/docs` regenerates it and lists the code-only examples (server mode, i18n, own document, dynamic pages, absolute links) with the reason.
- `examples/motion-*` (`@rivetjs/motion` guide pages `content/guides/motion/*`, dep `@rivetjs/motion` + `motion`): example frames render after the head is sent, so Motion entrances take the custom-property form — examples with entrances import `@rivetjs/motion/entrance.css` (test steps assert `data-mvv`, not `data-mve`).
- `examples/todo-list/src/routes/index.tsx`: user's WIP, don't touch.

## Icons (HIGH PRIORITY)
- Never hand-write SVG paths; never use UTF symbols or emoji (✓ × ▾ → ★ + − …) as icons. Use lucide (`lucide` package, icon data).
- In an example: `src/components/Icon.tsx` (copy from `examples/computed-total/src/components/Icon.tsx`), then `import { Plus } from "lucide"; <Icon icon={Plus} />`. Examples are standalone apps: each keeps its own copy.
- In the site / docs-kit UI: `import { Icon } from "@rivetjs/kit/icon"` (same API, default size 24; server + client). lucide has no brand icons: the GitHub links (footer) are text.

## Commands (repo root; `export PATH=/Users/denisseverin/.nvm/versions/node/v26.5.1/bin:$PATH` first)
- Typecheck + content/nav check: `NX_DAEMON=false npx nx run docs:typecheck --output-style=static --skip-nx-cache` (runs `prepare`: regenerates routes + error pages).
- Error pages: `node libs/docs-kit/cli.ts errors apps/docs` (regenerate `content/errors/`), `--check` (stale / missing / orphan = fail).
- Build + test some examples: `node libs/docs-kit/cli.ts check-examples apps/docs <id> <id> …` (production build of those frames only + their Chromium checks, out `apps/docs/.artifacts/check-examples/`). `examples apps/docs` only regenerates the frames + data and lists code-only examples.
- Full build: `NX_DAEMON=false npx nx run docs:build --output-style=static --skip-nx-cache` (cold, checks included: ≈ 12 s, peak tree RSS 1.5 GB incl. nx, 2026-10-09). Then `npx nx run docs:test` (vitest `docs`, depends on build). Units only: `npx vitest run --project docs tests/content.test.ts`.
- Serve built site: `npx nx run docs:serve` (:4321): watches content/examples/src/config + templates/ + libs/ and rebuilds incrementally, swapping atomically; `node libs/docs-kit/cli.ts serve apps/docs --no-watch` serves dist as is; `--port` overrides. Dev: `npx nx run docs:dev` = `serve apps/docs --dev` (Vite :4320 only: docs pages and example frames on demand, HMR).
- Content lint only: `node libs/docs-kit/cli.ts check-content apps/docs [--strict]`.
- Code fences: `node libs/docs-kit/cli.ts check-snippets apps/docs` (syntax + `@rivetjs/*` import drift; fence meta `nocheck` skips pseudo-code, `check` = full typecheck).

## Gotchas

- `content/guides/tooling/ai.md` documents portable `rivet-ui-design` installation for Codex/Claude Code/Cursor, local-clone and post-push remote commands, complete-bundle copying, automatic/explicit invocation, and optional MCP. The public bundles and starter copies are generated from `libs/mcp/ai`; keep this guide aligned with that source.
- `content/guides/components/framework-components.md` is the user guide of `@rivetjs/bridge` + `@rivetjs/bridge-react` / `-preact` (plan T17 part 1): keep its policy table, island options, ownership rules and limits aligned with `libs/bridge*/CLAUDE.md` (no Solid / Vue / Svelte or `persist` until they ship).
- `content/_charts.ts` imports `docs/benchmarks/*.json`: `serve` does not watch `docs/`, so a regenerated report needs a content touch or rebuild.
- Generated routes in `src/routes/(docs)/` are overwritten on every prepare/build: edit the `.md`.
- `src/styles.css` has `@source not "./generated/**"`: Tailwind otherwise scans the 21 MB examples manifest + `api.json` (Vite phase 16.7 s → 7.5 s); classes only present as text in that data are intentionally not generated.
- `tests/content.test.ts` / `site.test.ts` import docs-kit files by path: renaming docs-kit tools breaks them.
- Ports 4320–4326 are shared by both sites; don't start extra servers on them.
