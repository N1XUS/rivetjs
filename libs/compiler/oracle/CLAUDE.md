## Rules

- Diagnostics must match exactly. `code` and symbol `source` are compared after esbuild `minifyWhitespace` + `minifySyntax` (identifiers never renamed) — formatting may change, structure may not.
- Also consumed by `../tests/source-map.test.ts` (maps change no code, every case) and `../tests/i18n.test.ts` (unused `staticCalls` byte-identical).
- Must pass before any compiler change is reported: `sh scripts/zero-cost/check.sh` runs it last.

## Re-recording (intended output changes only)

1. Confirm the delta is intended (new ABI, renumbered symbols) and the zero-cost baselines are being updated in the same change.
2. Run `node libs/compiler/oracle/check.ts` → note failing case indices and diffs.
3. Rewrite only those lines: load the line, call `compile(...args)` / `moduleFacts(...args)` with the new wasm, store the raw result (not the esbuild-normalised form) with `JSON.stringify(result, tag)`. No recorder script is checked in — write a one-off in the scratchpad; keep line order and untouched cases byte-identical.
4. Mention the re-recorded case count in the commit message (precedent: `65808f17`, "four oracle corpus cases re-recorded"; wave 2: 18 cases for lazy children thunks + case 127 for resumable `onClickCapture` + 11 cases when the DOM-target `_slot` import moved to `@rivetjs/runtime/dom`; cases 1 + 17 (playground `app.tsx`, `defineRoute` `load()` / `render()` method shorthands) when R2 started wrapping method shorthands; H5: 38 diagnostic cases (54–62, 65, 66, 72, 73, 77–83, 85, 86, 88–93, 100–102, 123–126, 128–130) gained `code` + `severity`, case 71 for S6 (no `omitted()` slot for arrow handlers), 227–229 for C12 template compaction; FLATTEN-CMP: 17 cases (1, 17, 24, 25, 40–45, 111, 217, 225, 227, 229, 232, 233) — getter cells without `_rBind` / `_rAttr` (renumbered symbols), router/client `Link` static, resume `.map` list mounts, `<For>` list mount (111), MATRIX-1 spread style (227), v2 sole-child try/catch (227, 229)); CTX-1: 4 cases (227, 228, 229, 243) — v2 templates in `return` position lower to a block, no IIFE; V2-RESUME 2026-10-07: 13 cases (1, 24, 32, 40, 42, 44, 51, 175, 197, 210, 211, 213, 220) — resumed DOM tail drops package-import re-exports, resume spread symbols import `_spread` with a flags arg; SRV-ROWFN 2026-10-07: 12 resume server cases (17, 25, 39, 41, 43, 45, 115, 117, 205, 210, 212, 217, current numbering) code-only — hoisted `__rivetReadN` / `__rivetByN`, shared `__rivetCaps` row blocks, renumbered `__rivetFragmentsN`); V2-Q4 2026-10-07: cases 70 + 110 (server, bind-time handler evaluation) had a call as handler value (now RV1016) — sources rewritten to `({handler: Promise.reject(…)}).handler` / `(mark('event', …), undefined)`, outputs identical to the pre-RV1016 wasm).
