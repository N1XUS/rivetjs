# @rivetjs/compiler/tests

> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Vitest project `compiler` (root `vitest.config.ts`: `node("compiler", ["libs/compiler/tests/*.test.ts"])`, forks pool, native Node imports, `.tsx` via the Rivet loader hook). Baseline 71 files / 349 tests + 1 skipped (2026-10-22, M6-CUT-RUST: serialized-model tests deleted). DOM output with a getter props object imports `_p` / `_pg` from `@rivetjs/runtime/props` (per-layout `__rivetPropsN` factories): every loader that rewrites runtime specifiers (data-URL `load` helpers, `compiler-dom.test.ts` page routes) maps `@rivetjs/runtime/props` too; expectations match `__rivetPropsGetter(o, "x", i)` + `__rivetPropsN(() => …, data…)`, not getter literals.

## Commands

- All: `npx vitest run --project compiler` (`NX_DAEMON=false npx nx run compiler:test`).
- One file: `npx vitest run --project compiler libs/compiler/tests/<name>.test.ts`.
- Only top-level `*.test.ts` are collected; `compiler-dom/compiler.test.ts` is imported by `compiler-dom.test.ts` (fixture `compiler-dom/fixture.tsx`). Keep new tests flat in this directory (the glob is fixed). `dom-rows.test.ts` imports its helpers from `dom-rows/` the same way.

## Rules

- Tests exercise the committed `../rivet_compiler.wasm`: rebuild after Rust changes or expectations are stale.
- Data-URL / browser harnesses map runtime specifiers by hand: a new compiler import (e.g. `@rivetjs/runtime/slot`) must be added to every `.replaceAll("@rivetjs/runtime/…")` list in these tests.
- Vite tests build real temp projects (`mkdtemp` under `.artifacts/`, `createServer` / `build`, removed in `after`). Keep them self-contained.
- Compiler output assertions are exact strings by design (zero-cost tracking); when an intended ABI change moves them, also re-record the oracle corpus (`../oracle/CLAUDE.md`) and the zero-cost baselines.
