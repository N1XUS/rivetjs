# @rivetjs/docs-kit/tools/content
> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Content pipeline: `content/**.md` → route modules in `src/routes/(docs)/` (path-less group: `content/guides/components.md` serves `/guides/components/`) + generated data.

## Layout
- `generate.ts`: `generateContent(root, { symbols?, dryRun? })` → `{ pages, written, todo }`. Validates `_nav.ts`: `areas` required, every section's `area` exists, every area has a section; generated `nav.ts` exports `areas` (id, title, href = first section's href) + `sections` (with `area`); routes import `Icon` + the lucide icons their Markdown uses (`Rendered.icons`). Writes routes, `src/generated/{nav.ts,pages.ts,terms.json,highlight.css,starters.ts}` (`starters.ts` = StackBlitz payloads; skips the starters' AI instruction files `AGENTS.md` / `CLAUDE.md` / `.claude/` / `.cursor/` / `.github/copilot-instructions.md`), copies `../../routes/**` into `src/routes/`, deletes stale generated routes. Fragments: `content/_<name>.md` (no frontmatter, not a page) → `src/generated/fragments/<name>.tsx` (`export default function Fragment()`, kit imports for the components it uses; links join the link check; stale fragments deleted) — wide pages (home) import them for code fences / compiled output / callouts. Also `glossaryTerms`, `contentPathOf`, `ROUTES_DIR`, `GENERATED_DIR`.
- `markdown.ts`: `renderMarkdown(body, ctx, lineOffset)` → JSX + headings + links + used components + `icons` (lucide names); `slugger`, `internalHref`, `attr`, `text`, `fenceMeta(meta)` → `{ title?, group?, verdict?, compiled?: "auto" | "stacked" | "tabs", open? }`. Imports `@rivetjs/compiler` (`compile`, sync wasm) for compiled fences: errors fail the fence, `warnings` print once per fence + message (`formatDiagnostic`, origin `docs-kit`, `console.warn`). unified + remark-gfm + remark-directive.
- `frontmatter.ts`: YAML subset parser + schema (`splitFrontmatter`, `validateFrontmatter`, `STATUSES`, `TEMPLATES`).
- `highlight.ts`: plain code lines (`codeLines`: line notation `// [!code highlight|++|--]` → marks), `highlightCSS()` = token class rules from the github-light / github-dark palettes (`src/generated/highlight.css`), `LANGS`; page tokens are coloured in the browser (`components/highlighter.ts`); fragments (`content/_*.md`) are coloured at build: `generate.ts` passes `RenderContext.tokens` = `loadTokenizer([tsx, ts, js, json, bash, css, html])` (same classes; `<pre data-hl>` = the browser highlighter skips it), so lean pages (home) show coloured code with no JS. Test `apps/docs/tests/content.test.ts` "build-time tokens".
- `plugin.ts`: `docsContent()` Vite plugin: generate (examples, then content) on `config` — skipped under env `DOCS_KIT_GENERATED` (a docs build's server-bundle child, `tools/vite-build.ts`: the client child just generated) — and regenerate on dev changes under `content/` (`.md`, `.ts`) / `examples/`.

## Markdown features
- Directives: `::example{id=…}` → `<Example>`, `::api{symbol="@rivetjs/pkg/entry#name"}` → `<ApiCard>`, `::starter{…}` → `<StarterButton>`, `::chart{id=… compact?}` → `<BenchChart chart={…spec inlined as a literal…}>` (specs from the app's `content/_charts.ts` `charts`, loaded by `generate.ts` like `_nav.ts`; unknown id = error); text `:term[…]` (glossary at `content/reference/glossary.md`), `:kbd[…]`.
- Callouts: `:::note`, `:::tip`, `:::warning`, `:::gotcha` (others: error) → `<aside class="callout callout-<kind>">` with a `.callout-title` (lucide Info / Lightbulb / TriangleAlert / OctagonAlert + label).
- Headings h2–h4: `<hN id><a class="heading-anchor" href="#id">` (+ Link icon on h2/h3, shown on hover/focus).
- Code blocks: `<figure class="code-block">` with a `div.code-head` on every fence (Avoid/Prefer pill, `.code-lang`, `.code-title`, `.code-grow`, `CopyButton` icon; one copy button per tab set); fence meta: `title="…"` (file name in the header), `avoid` / `prefer` (pill + tinted border: `.code-avoid` / `.code-prefer`), `group="x"` (adjacent fences with the same group → one file-tab set: radio inputs, no JS, labels = titles, ≤ 8 files, verdict of the first fence), `check` / `nocheck` (read only by `docs-kit check-snippets`: full typecheck / skip), `compiled` (tsx/jsx only; compiles the fence for the `dom` and `server` targets at build time, compile errors fail the build; `auto` = stacked when both outputs ≤ `STACKED_MAX_LINES` (32) lines, else tabs): stacked = source + "Compiled output" switch (`label.code-switch.code-show`, checkbox `role="switch"`) revealing `div.code-out[data-pagefind-ignore]` with "Compiles to" Browser / Server radios (`compiled-N`) over `pre[data-pane=dom|server]`; `compiled="tabs"` = `File.tsx` / `dom.js` / `server.js` editor tabs + "Side by side" switch (`.code-split`, ≥ 900px). `open` = switch on initially. Radio group names are `compiled-N` / `code-tabs-N` per render; fragments (`_<name>.md`, several on one page) prefix them with the fragment name (`home-hero-compiled-1`) so two blocks never share a group (a shared group leaves one block with nothing checked). Compiler-inserted names (`__rivet*`, `_el$N`) get `.code-rv`. CSS only (`:has()`), works without JS. Frontmatter: `title`, `description` (≤160 chars), `template`, `status`, `since`, `tags`, `related`, `spec`.

## Rules / invariants
- No raw HTML in content (error). No `style` attributes from highlighting (compiler rejects them).
- Errors name the file (and line); unknown directive / term / example / symbol / starter / internal link / related page = build error.
- Every content file appears in `_nav.ts` exactly once; every nav entry has a file.
- `site:<name>/<path>` links → `siteHref` against `DocsSite.sites` (unknown name fails the page); absolute localhost/127.0.0.1 links land in `Rendered.localLinks`.
- `TODO-CONTENT` marks placeholder pages (listed by `check-content`, fail with `--strict`).

## Gotchas
- `markdown.ts` / `frontmatter.ts` / `highlight.ts` / `generate.ts` are imported by `apps/docs/tests/content.test.ts` and `site.test.ts`: keep paths and export names.
