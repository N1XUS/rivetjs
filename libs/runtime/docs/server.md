# @rivetjs/runtime — server area

> **Keep this file current:** ALWAYS update this file in the same change whenever the server rendering code changes (ABI, writer protocol, value kinds, gotchas).

Files: `server.ts` (renderer), `template.ts`, `omitted.ts`, `server-structural.ts`, `server-async.ts`, `server-boundary.ts`, `server-suspense.ts` + `server-suspense-slot.ts`, `server-spread.ts`, `server-router.ts`, `node.ts`. Resume recorder: `resume.md`.

## Contract

- `renderToString(value, { signal, variant })` / `renderToWriter(value, writer, …)` — synchronous when nothing suspends; returns a Promise only when a child or write actually suspends. Function factories run in request-owned roots until completion / abort; `finish()` disposes scopes and the request root.
- `ServerValue` = string | number | bigint | boolean | null | undefined | `ServerTemplate` | `ServerScope` | `CompiledElement` | `AttributeSlot` | `OmittedSlot` | `VariantValue` | array | thenable | `() => ServerValue`.
- Records are private-branded (`TEMPLATE`, `ATTRIBUTE`, `COMPILED`, `LIST`, `SPREAD`, `SCOPED`, `CAUGHT`, `VARIANTS` — `Symbol.for` brands so duplicate module instances agree; `omitted()` slots are `Omitted` class instances with a `Symbol.for("rivet.omitted")` prototype brand). `admit` observes formed input once without running factories; thenables normalized once per object. Compiled admission recurses into every object slot (attribute records with a scalar value inline, no call), so traversal dispatches a compiled child of an admitted compiled record / list tape straight to `visitValue` (`visitChild`) — admission stays linear in nesting depth (was quadratic: re-admitted per level). Same for the compiled rows of a server `For` array (`ROWS`, `server-structural.ts`: runtime-formed, never mutated — `arraySequence` skips their second admission), the `SPREAD`-branded record array of `spreadAttributes` (admits its records' values; no identity / thenable probe of the array, `visitValue` goes straight to `arraySequence`), an omitted slot (no probe; an inert value — primitive, or a plain function: `Function.prototype`, no own `then` — is neither admitted nor awaited, `omitted.ts` `inert`), an awaited value (`awaitValue` admits once inside `within`) and a function child's output. A continuation after a wait (inside = null) re-enters the owner once for the rest of an array / template (`arrayWithin`, `templateSequenceWithin`), not per item.
- Compiler server ABI: `template(fragments, slots)`, `compiledTemplate`, `attribute(name, value, namespace)` (`template.ts`: escaping, boolean attributes — `true`/truthy → bare name, falsy → omitted, except `hidden` with a non-empty string: written verbatim (`hidden="until-found"`) —, `media` namespace for `data:`-allowed URL attributes), `omitted(value)` (evaluate, emit nothing; `null` for an inert value — primitive / plain function — so absent handlers and refs cost no slot), `spreadAttributes` / `spreadChildren` (`server-spread.ts`: `on[A-Z]` functions dropped, other functions read once, `children` kept; null / undefined values make no record — after the name check — but still clear an earlier key of the same output name and hold the position for a later alias; `MEDIA_URLS` checked only for 3–6-char names; 4th argument `names` (resume `_rSpread`) receives the written attributes' names in output order, absent ones left out), `_variants` / `_variantTemplate` / `_variantValue` / `_variantOf` (i18n variant index), `_listPlan` / `_list` (list mounts: `items.map` with intrinsic-identical observable operations, captures on a tape; `OPEN` / `CLOSE` slots bound flattened child plans — compiler tape layout counts them).
- Components: `For`, `Show`, `Switch`, `Match`, `Dynamic`, `Portal`, `Provider` (`server-structural.ts`, `SCOPED` records — a server `Provider`'s record owner is its provide owner (no extra root); the renderer admits a scoped record once (`scopes` is its identity cache, no thenable probe) and dispatches its value without re-admission (nested providers used to rescan their compiled subtree per level); `For` row getters are constants (`ConstantGetter`) so resume serializes them; without `server-resume` loaded (no row hook) rows run under the For's single root and render as a plain array — no per-row root / `SCOPED` record / admission (P1: rivet-for micro 0.70 → 0.50 ms/page at 1000 rows); resume renders keep per-row roots + row regions), `Async` / `lazyComponent` / `clientOnly` (`server-async.ts`: awaits children, never emits fallback except in streaming resumable renders; `withRequestSignal`), `ErrorBoundary` (`server-boundary.ts`: buffered content, `fallback(error)` on failure), `Suspense` / `startTransition` / `useTransition` (`server-suspense.ts`, pay-per-use install via `server-suspense-slot.ts`), `Router` / `defineRoute` (`server-router.ts`), `ChunkGroup` (identity; chunk grouping + preload level), `ref()` (server: `r()` undefined; resume: cell → element id), `clientEffect` / `clientEvent` (no-ops on the server; recorded by resume compilation through `_rEffect` / `_rClientEvent`).
- Writers (`node.ts`): `StringWriter` (bounded buffer), `NodeStreamWriter` (backpressure-aware byte writer, pooled 128 KiB slabs, 48 KiB chunks + a microtask flush when the render pauses, `writeBytes` / `writeInteger` fast paths the renderer uses when present — `Sink` interface in `server.ts`). Byte writers share `server-slab.ts` `SlabWriter` (exported from `/server`): writeText / writeBytes / writeInteger / claim / commit over `bytes` / `start` / `offset`, flush at `threshold` (0 = every write), `schedule()` for a deferred flush while `scheduled` is false; subclasses implement `write` / `flush` / `renew` / `oversize` (`NodeStreamWriter`, router `BodyWriter`).
  - `writeText(text)`: HTML-text escape fused into the UTF-8 encode (strings ≤ 64 units inline via `server-bytes.ts` `putText`, longer: regex + native encoder); byte-identical to `escapeText` + encode (lone surrogates → U+FFFD). The renderer calls it for string children on byte writers (ErrorBoundary buffer implements it too).
  - Raw-slab protocol `claim(n)` / `commit(end)` + readonly `bytes` / `offset`: `listValue` writes a whole list row (`rawRow` for plain scalars, else `rawTemplate`) and `recordBytes` a whole compiled record (`rawTemplate`: one pass, `rawPut` — the checks fused with the write into the room the slab already has, committed only on success; `RAW_NOT` → generic path, `RAW_ROOM` (the room ran out) → `rawSize` + `claim` + `rawWrite`) — safe integers, strings ≤ 64 units, omitted values, attributes with a non-boolean name — one room check + one threshold check, no abort check per piece, instead of a writer call per fragment / slot; any other slot → the per-piece path for that row / record. A compiled record's slots may also be attribute records holding null / undefined (nothing written), a string ≤ 64 units (`putAttribute` = `escapeAttribute` + UTF-8; URL names checked with `unsafeUrl` like `encodeAttributeValue` — single URLs starting with `/` `#` `?` `.` skip the check, unsafe ones fall back so the generic path writes `about:invalid` + the dev warning), and nested compiled records (≤ 8 levels, no locale variants) of such slots: a resumable For row with its `<Link>` = one claim/commit (FLATTEN-RT: router resume lane 1000 rows 541 → 179 framework calls/row, self 6.3 → ~3.4 ms/page). Boolean / enumerated (`hidden`, `popover`) attributes, functions, promises, arrays, long strings stay generic. Output bytes identical (`tests/gap-wr-writer.test.ts`, `tests/server-raw-records.test.ts`); chunk boundaries may move by < one record.
  - List rows through WebAssembly (`server-rows.ts`, module bytes generated by `scripts/gen-row-wasm.mjs` into `server-rows-wasm.ts`): before the per-row path, `listValue` hands runs of rows to `_listRows` (byte writers with `claim` / `commit`, plans from `_listPlan`, not row-region plans). Per row each string slot is copied into the module's memory with one native UTF-8 encode (`Buffer#utf8Write`, else `encodeInto`) and int32 slots into a number array; one SIMD call per ≤ 128 KiB chunk interleaves the plan's fragments, escapes text (`&<>`) / attribute values (`&<>"'`) and writes the digits; the chunk is copied into the slab in ≤ 32 KiB claims (backpressure: all accepted, the first wait returned with the next row). A row it does not take (a string in a URL attribute, a null / boolean attribute, an object / function child, a non-int32 number) is written by the per-row path, then the emitter continues; a plan with a boolean attribute is never taken. No WebAssembly, or compiling from bytes refused (Cloudflare Workers, strict CSP runtimes): the first call fails a self-check and the process keeps the per-row path. Bytes identical either way (`tests/server-rows.test.ts`: seeded fuzz, forced fallback).
  - `early` (default true): once 128 KiB (`EARLY`) were handed to the sink, the writer uncorks the sink once (a Node `ServerResponse`'s own cork — Node 26.11 corks the response and buffers chunked frames in it — else `sink.socket`), so the response's head leaves while the rest renders (Node's response otherwise corks a tick's writes into one writev at the end of a synchronous render). Pages under 128 KiB keep one write; bodies run to completion (no event-loop yields — the 2026-10 `share` slicing was removed: its yields kept decoded page data of every interleaved request alive, GC + CPU at c=10). Opt out: `{ early: false }`.

## Rules

- Perf first: `server.ts` is the hot path of the SSR benchmark vs Razor (`apps/ssr-bench`, lane hashes in `scripts/zero-cost/lanes.txt` are built from `libs/runtime/server.ts` through an alias). No allocations per slot without a measured win; attribute prefixes are pre-encoded (`rawAttribute`), `PRESIZED` buffers.
- Keep list-mount invariants: `_list` assumes ordinary intrinsics (`Array.prototype.map`, thenable detection); any new observable operation in `_list` breaks the "same observable operations in the same order" guarantee.
- `omitted.ts` and `Symbol.for` brands must stay the only cross-instance identities.
- Error boundaries buffer: a failed buffered child replaces its buffer with the fallback; streamed renders write the fallback as a segment (`resume.md`).
- Resume-mode modules lower `.map` rows to list mounts only when the row holds no resume site (recorder slots are not modeled by list plans); keyed `<For>` list mounts are non-resume only.
- Server `For` `$list: [plan, each]` (compiler-private, FLATTEN-CMP-3): with no row hook installed the rows render through `_list` (`server.ts` installs it via `_forListMount`: no import cycle); with the hook (`server-resume` loaded) `$list` is ignored and `children` runs per row.
- `.ts` modules are not rewritten per target: never import `@rivetjs/runtime/dom` from a `.ts` file that runs on the server.

## Gotchas

- Records are class instances with lazily pinned shapes (`_compiledRecord` / `_attributeRecord` / `_scopedRecord`): V8 drops weakly held transition maps after a full GC with no live instance and deopts every renderer function that embedded them. Don't build records as `{ [BRAND]: … }` literals.
- Nested compiled records render by direct recursion: string writers join one chunk across records and primitive attributes (flushed before user functions, object coercion, unsafe URLs); byte writers skip `rawTemplate` size passes along a raw path that already failed (`rawPath`).
- `renderToString` of a page with a pending `Async` returns a Promise — callers that need sync output use `@rivetjs/runtime/testing/server` (`renderToString` always resolves).
- `ChunkGroup` without resume has no effect; `preload` on `<audio>`/`<video>` is the native attribute, elsewhere the resume directive (JSX types encode this).
- `attribute()` neutralizes `javascript:` / `vbscript:` / (outside media sources) `data:` URLs to `about:invalid#rivet` (dev warns once per attribute+scheme).
- Style strings are compile errors; style objects go through `style.ts` (unsafe values — `url()`, `expression()`, `javascript:` — dropped, dev warns). `Picture` `style` (a declaration string) runs each declaration's value through `_styleValue` (unsafe / malformed declarations dropped, SEC13; `image-markup.ts`). A spread `style` key (`server-spread.ts`) encodes through the same `_style` / `_styleAttr` as an explicit `style={obj}`; a string value throws.
- `Async` (`server-async.ts`): the boundary's `AbortController` is created only when `work.signal` is read (prototype getter of the frozen `Work` instance; `get` / `run` are own closures — never a frozen object literal with an accessor: each was a fresh old-space map whose accessor pair kept the request graph alive across scavenges, router `/page` 15% of allocation promoted); otherwise abort is a flag + stored first reason (`live()` materializes the signal only to throw). A read after dispose still sees `aborted === true`. Saves ~4 µs per boundary (default `abort()` builds a stack-capturing `DOMException`). `lazyComponent` always reads it (passes it to `lazyFunction.load`).
