# @rivetjs/runtime — client DOM area

> **Keep this file current:** ALWAYS update this file in the same change whenever the client DOM code changes (ABI, ownership, delegation, gotchas).

Files: `dom.ts` (public API + structural components, re-exports the compiler ABI), `dom-v2.ts` (compiler ABI), `dom-v2-spread.ts`, `dom-v2-controls.ts`, `dom-adopt.ts` (resume adoption), `dom-suspense.ts` + `async-coordinator.ts`, `dom-router.ts`, `url.ts`, `hot.ts`, `id-dom.ts`, `image-dom.ts`. Dev façade: `dev/dom.ts` (`development` condition; compiled DOM modules import `@rivetjs/runtime/dom`, so it covers all compiled output). DOM v1 (ranges, construction context, `template` / `component` / `bind*`) was deleted 2026-10-07 (spec `docs/design/specs/2026-10-06-dom-v2-only-design.md` phase e).

## Public API (`dom.ts`)

- `mount(factory, container)` / `render` / `attach` — `createRoot` + `_insert(container, factory())`; `rootContainer` (saved / restored) gives `_constructionDoc()` = its `ownerDocument ?? document`.
- Components return a `DOMValue` (Node | array | accessor | scalar) and own nothing; `_c(fn, props)` = untracked call.
- `Output` (`_dom = { output, nodes, park }`): content inserted between two empty Text anchors in a detached fragment under its own `createRoot` (owned by the current owner); `nodes(out)` collects start…end at read time; `park(out, into)` moves them to a holder fragment; disposal removes them (`onCleanup`). Used by `Async` (one per generation; the coordinator's `swap` gets `next.start.parentNode`), `Suspense` (content + fallback; hidden content parked in a holder so inner `_insert(null, …, end)` keeps a parent) and `ErrorBoundary` (children bound eagerly inside `catchError`, so a nested boundary's failure is caught by the nearest one).
- `Provider` — `provide(token, value, …)`; accessors in its content are deep-mapped through reactivity `_scoped` (each read in a fresh child scope of the provide owner: later reads still see the value). Plain content (nodes / scalars / arrays) passes as is, so nested providers do not re-stage their subtree (`tests/provider-context.test.ts`).
- `For` / `Show` / `Switch` / `Match` are `_for` / `_show` / `_switch` / `_match` (below) cast to the public types; `Dynamic` (`_c` for components; tags: `createElementNS` with HTML → unknown → SVG → MathML fallback, then `_spread`, `_insert` children, `bindRef`; unsafe tags / void-with-children throw), `Portal` (`_insert(mount ?? document.body, children)`), `ChunkGroup`, `lazyComponent` / `clientOnly` (`_warmLazy`), `Async`, `ErrorBoundary`, `Suspense` / `startTransition` / `useTransition` (`dom-suspense.ts`), `Router` / `defineRoute`.
- Resume hooks: `_dom` (suspense), `_resumeSelect` (still emitted by dead Rust serialized paths; plan M6).
- Public: `ref()` (signal-backed `Ref<T>`), `bindRef`, `clientEffect(fn, { when })` (microtask-deferred owned effect), `clientEvent(target, type, handler, { when, passive, capture, once, preload })` (`passive` defaults true for `scroll wheel touch* pointermove resize`; `"media:(q)"` targets; runs through `_dispatch`, skipped once its owner is disposed).

## Compiler ABI (`dom-v2.ts`; compiler list `compile/dom_v2.rs` `V2_ABI`) — no per-template bookkeeping

- Contract (plan `docs/design/plans/2026-10-05-beat-everyone.md` §DOM v2): a template returns its cloned `Node`; bindings, components and inserted children belong to the **nearest reactive scope** (mount root, insert effect, list row). Imperative edits to compiled DOM are not tracked; a removed region's nodes are removed and its owners disposed by the owning scope (Solid semantics).
- `_tpl(html, flags)` (1 SVG, 2 MathML, 4 fragment) → `() => Node` clone (parsed lazily per document; clones come from the inert template document — live-document clones cost krausest 07 script +6–8% — and are adopted on insertion, or earlier by `_ref`, which adopts the whole clone before user code sees the element; templates with custom elements (`<x-y>` / `is=`) and fragments clone a live-document root so elements upgrade at clone time; no document → `Error("Construct DOM inside mount(): no document")`); `_c(fn, props)` untracked call; `_cp(fn, () => props)` snapshot props; `_fx(fn)` = `_bindingEffect` (one closure per dynamic binding, e.g. `_fx(() => _cls(el, expr))`); `_t(el, value)` text/insert state on `el.$$t`; `_tx(text, value)` (IMPL-DOM F2) the same on the template's placeholder Text node (`<a> </a>`, compiler `dom_v2_text.rs`): scalars write `data` (no expando, no compare), the first node / array / accessor switches to insertion before the emptied placeholder (slot in `text.$$s`); `_textValue`, `_setAttr`, `_attrValue` (URL-checked), `_attrSet`, `_attrWrite`, `_className` / `_cls`; `_insert(parent, value, marker)` (accessor → effect; an accessor or an array holding accessors returned by a read binds in a nested effect, each array accessor read in its own cell (`cells`: binding → signal), so an item's update never re-runs the read that built the array nor its siblings; arrays reconcile by node identity); `_for({ each, by, children })` → `() => Node[]` rows as roots under the list owner (`index` accessor only when `children.length > 1`; props typed like public `For`: `each` accessor, `by` required — the runtime still tolerates an array / missing `by`; a persistent key → row Map matches keys and detects `Duplicate For key` in O(changed rows), rows stamped per pass; rows kept without key work at an equal-item prefix / suffix keep their key — a suffix row moved by a length change is kept only while `by(item, newIndex)` still equals it (index-keyed `by`); the accessor's node array is taken by `assign` without a `flatten` copy and refreshed in place from ranged rows' live nodes before the next reconcile). `_show(props)` / `_switch(props)` / `_match(props)` = public `Show` / `Switch` / `Match` ( branch = memo of `{ index, value }`, re-picked only on truthiness / keyed value change; function content runs under `_rootIn` and is disposed on switch; eager content cached per branch, fragments captured as node arrays; `_match` returns a comment marker carrying its props in a WeakMap, `_switch` collects markers from its children).
- `_on(el, type, handler)` — **delegated**: handler stored on the node as `el["$$" + type]`, owner on `el.$$o`; one `document.addEventListener(type, dispatch)` per (document, type). `dispatch` walks from `composedPath()[0]` up `parentNode` / shadow `host`, runs each node's handler via reactivity `_dispatch(owner, handler, target, event)` (batched; skipped if the owner is disposed; no `disabled` skip), sets `currentTarget` to the handler's node (data property, not accessor), stops at `cancelBubble`. A shadow root met on a delegated path gets its own listener for that type (`watchShadow`), so events that stay inside one shadow tree (pointer over / out, focus in / out between shadow nodes) dispatch too. Only for **bubbling** event types — the compiler decides.
- `_listen(el, type, handler, options)` — direct listener for non-bubbling / capture events, removed with the owner.
- `_spread(el, object | () => object, flags)` — `{...x}`: merged object (spreads + plain attributes, source order, later key wins); one `_bindingEffect` when it is a thunk or a static object holds accessor values, keys diffed per run (`children` / `ref` skipped; `className` → `class`, `htmlFor` → `for`). `on[A-Z]*` keys: delegated bubbling types compose after an explicit `_on` handler (`el["$$"+type]`), others / `*Capture` are direct listeners (one per type, bound on the first function value — an unset key installs nothing —, current handler read at dispatch, removed with the owner); `class` → `_cls`; `style` → `_applyStyle` (style object diffed like `_bindStyle`; a frozen object on an element without inline style is written as one cached `cssText`; strings throw); other names validated once (`innerHTML` / `srcdoc` throw) then `_attrWrite`. `flags & 1`: no JSX children — the object's `children` is inserted (`_insert` of a `signal`, default equals: written only when the `children` value changes, so an attribute-only re-run keeps the child nodes; resumed: the server content stays until `children` changes — see `CLAUDE.md` spreads). Tree-shakes with `DELEGATED` / the name regexes when unused (krausest byte-identical). Lives in `dom-v2-spread.ts` (re-exported by `dom-v2.ts` / `dom.ts`): chunkers keep it, and `style.ts`, out of shared eager chunks unless an eager template spreads.
- `_ref(el, fn)` = `bindRef` (`ref()` signals and callbacks).
- `_slot` (lazy-children brand) is defined in `dom.ts` for the DOM target (twin of `slot.ts`'s, same `Symbol.for` brand) so compiled modules keep it in the dom chunk.

## Rules

- `sideEffects: false`: `dom-suspense.ts` installs its coordinator on import — keep it the only top-level install.
- No construction context: bindings re-running later use `_constructionDoc()` (mount container's document, else the page document); the insertion parent (`dom-v2.ts` `insertionParent`, set by `within`) picks SVG parsing for `_tplNs`.
- Reconcile wipes a parent with `textContent = ""` when the list owns all of it (no marker siblings).
- Hot replacement (`hot.ts`) tracks live instances (`live: Set<Instance>`) and depends on signal creation order; Vite dev only, never in builds (`hot-reactivity.ts` swaps `signal`).
- `id-dom.ts` ids `rvc<n>` never collide with server `rv<n>`; `withIdScope` shared.
- Browser tests (`tests/dom.test.ts`, `tests/dom-v2.test.ts`, `tests/*-browser.test.ts`) serve these files to Chromium by explicit list — add new imports there.

## Gotchas

- Delegation differs by page kind: resumed pages use the loader's delegation (see `resume.md`), client pages document delegation (`_on`), `_listen` / `clientEvent` direct listeners; ordering differs between them (resumed `onClick` vs capture `useInteractOutside`). A synthetic non-bubbling event (`new MouseEvent("click")`) reaches no `_on` handler.
- `clientEffect` runs a microtask after mount; on resumed pages at `when` (`load | idle | visible | interaction | media:`) instead.
- A `ref()` holding a server element removed by region replacement keeps it (limit); `bindRef` cleanup resets only if the ref still holds that element.
- `Portal` appends to `props.mount ?? document.body` and removes on cleanup; cdk overlay layer builds on it (no native dialog/popover).
- `_setProp` rejects `on*`, `innerHTML`, `outerHTML`, `srcdoc`, `style`, `__proto__`, `constructor`, `prototype`. A URL-named property (`url.ts` `URLS`) set to an object (`new URL(…)`) is checked as `String(value)` and assigned as the object when safe (SEC4).
- URL lists: `srcset` / `imagesrcset` / `ping` split on whitespace / `,` / `;`; SMIL `values` on `;` only, each entry stripped of controls / spaces before the scheme check (SEC3: `java\tscript:` inside an entry). Compiler literal twin: `html.rs`.
- Trusted Types (SEC2): the `rivet` policy is module-private in `dom.ts`; `_parseHTML(doc, html)` (internal ABI, `_tpl`) writes markup only into a fresh inert `<template>` and returns its content — no export returns TrustedHTML. A second runtime copy reuses the first one's writer through `Symbol.for("rivet.html")` (CSP `trusted-types rivet` refuses a duplicate policy without `'allow-duplicates'`); `createPolicy` refused by CSP → plain strings (the sink reports the violation).
