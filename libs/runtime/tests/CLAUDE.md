# @rivetjs/runtime/tests

> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Vitest suites for the runtime (root `vitest.config.ts` projects `runtime` and `runtime-dev` = same files under `--conditions=development` + recording devtools hook; `*.test.ts` at this level only — subfolders hold fixtures and are not globbed; the `*.test.tsx` files in `refs/`, `suspense/`, `testing/` are run as child processes by `refs.test.ts`, `suspense.test.ts`, `testing.test.ts` through the register hook). Baseline 2026-10-06: 153 files, 836 passed, 3 skipped (runtime + runtime-dev).

## Rules

- Browser suites import runtime sources by explicit path lists (`dom.test.ts` `routerFiles`, `dom-router.test.ts`, `dom-async.test.ts`, `dom-boundary.test.ts`, `resume/harness.ts` `sources`, `libs/compiler/tests/compiler-dom.test.ts`; `dom-v2.ts` → `dom-v2-spread.ts`, `dom.ts` → `dom-v2-controls.ts` + `dom-adopt.ts`): a new relative import inside `dom.ts`, `dom-v2.ts`, `dom-derived.ts`, … must be added there (404 in Chromium otherwise).
- `derived-selection-browser.test.ts`: real Vite build + `renderDocument` page, client modules held across a focused selection; dirty first input and pristine NUL-normalized controls keep value, node identity, focus and selection direction after adoption; the same trusted insert replaces the selection in adoption and in a fresh CSR mount.
- `dom-lite-browser.test.ts` (ZERO R4 / R5): real derived server target + hand-written residual (`Counter$a`, `$c` → the compiled ordinary module); lite page adopts only the clicked boundary, never fetches `/dom-derived.ts`; document listeners equal at N=1 and N=1000; fallback (bad walk, wake-list key) → full runtime + `$c`; full runtime runs `$a` (R5) and falls back through `$c`. Harness (`tests/resume/harness.ts`) serves the lite leaves `/dom-lite-core.ts`, `-attr`, `-write`, `-list`, `-model` (RT-DIET).
- `derived-listen-browser.test.ts` (D5, ZERO R2): listened types written into tail v2 `n[i][2]` by the test (by name); static text / native checkbox → no runtime; independent boundary in a non-listening root loads only its chunk; no types = root adopts (pre-D5); `*` / other-type names.
- Resume fixtures assert `__componentRuns` stays unset in the browser before the first interaction — a component running on load is a bug, not a flake.
- `resume-loader.test.ts` fails when `resume-loader-derived.min.ts` is stale: run `node libs/runtime/build-loader.ts` after touching `resume-loader-derived.ts`.
- Keep test locations: the root vitest config is not editable from this package; new suites go in this folder as `*.test.ts`.
- Playwright Chromium must be installed (`npx playwright install chromium`); suites run with no per-test timeout (`testTimeout: 0`).
- `derived-cond-root.test.ts` (ZERO C3 2026-10-25, real derived server + DOM targets, skips without `hasDerivedModel()`): a conditional root over independent cards ships no record (cards top-level, parent 0; a dependent child still keeps its parent); a card's first click adopts only that card (O(1) nodes, no component run before input). ZERO REGRESS: an independent child below a `*` listener (the `_rListen` root) ships no props and no `INDEPENDENT` flag.
- `derived-callsite.test.ts` (ZERO CALLSITE 2026-10-26, real derived targets): `resume.site` / `sites` / `free` → the proven `Part` site and `Counter` ship `INDEPENDENT | CTXFREE` + props, the unproven `Part` site stays dependent; first clicks on them adopt standalone (the page root never runs), the unproven one adopts with its parent and keeps the adopted parts' state; without the proof an independent record's click still adopts its ancestors (intake 3).
- `derived-read-back-browser.test.ts` (ZERO REGRESS 2026-10-26, real derived targets): card props read back from the markup — record without them, names entry `[name, url, "click", "title=ff author=ffn pages=fn"]`, CR / empty strings ship; first clicks adopt every card with the server's text, prod + dev (no mismatch warning).
