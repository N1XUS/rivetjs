# @rivetjs/runtime

> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Target runtimes the compiler emits calls into: server rendering (string / writer / streaming), client DOM (one ABI: templates, delegated events, `_insert` value slots), resumability (server recorder → state table → inline loader → client resume runtime), JSX types, dev façades. Deps: `@rivetjs/reactivity`; `@rivetjs/compiler` is an optional peer (testing register only).

## Layout (flat by design)

One file per public subpath, helpers beside it with an area prefix. NOT converted to `<name>/index.ts` folders: `apps/ssr-bench/build.ts` aliases `libs/runtime/server.ts`, `libs/compiler/tests/*` import `../../runtime/server.ts` / `node.ts`, `apps/docs/api.config.ts` reads entry files by path, `scripts/gen-events.mjs` writes `jsx-events.ts`, `libs/cdk/tests` import `tests/resume/{compile,harness}.ts`, and every move would have to keep `scripts/zero-cost/runtime.txt` hashes identical. Areas:

- **server** — `server.ts` (renderer; hot file), `template.ts` (template/attribute records, boolean attrs; escaping lives in `escape.ts`), `server-structural.ts` (`For`/`Show`/`Switch`/`Portal`/`Dynamic`, `SCOPED` records; a `Dynamic` tag's `style` is a style object like DOM `_spread`'s — `_styleAttr(_style(obj))`, strings throw; was `Unsafe attribute name` before 2026-10-12, MOTION T5), `server-async.ts` (`Async`, `lazyComponent` (once its module is loaded the component renders synchronously: no load promise / signal link per render), `clientOnly`, request signal; disposal aborts a read signal with one module-shared `AbortError` DOMException — creating one per request was ~3% CPU; the work handle is a frozen `Work` class instance (shared map; `signal` prototype getter, `get` / `run` own closures) — a frozen object literal with an accessor got a fresh old-space map per boundary whose accessor pair held the getter closure, so every request graph survived scavenges until mark-compact (IMPL-TRANSPORT 2026-10-09: router `/page` 0 rows 15.7% → 4.7% of allocation promoted, in-process 0.060 → 0.040 ms/req; Docker `/resume` 1000 rows c1 2.75 → 2.20 ms CPU/page; most of the remaining mark-compacts were the router's body stream holding the render scope — `libs/router/server/CLAUDE.md` "Retention", IMPL-ALLOC). Never freeze per-call object literals that carry accessors in server hot paths), `server-boundary.ts` (`ErrorBoundary`; resumable renders link its content scope to the claimed site — `a` status 3 — so the browser re-creates the site when a resumed binding inside fails, CORE-GAPS (b)), `server-suspense.ts` + `server-suspense-slot.ts` (pay-per-use Suspense), `server-spread.ts` (`{...x}`), `server-router.ts`, `omitted.ts`, `node.ts` (`NodeStreamWriter extends SlabWriter`: pooled 128 KiB slabs, chunks handed to the sink at 48 KiB (`THRESHOLD`) and in a microtask once the render pauses — a shell before an await leaves at once; the microtask flush ignores backpressure (the next write's flush returns it; its wait's rejection is swallowed — a close / abort reaches the render through the next write or `finish`, never as an unhandled rejection, `tests/node-writer.test.ts`); OPT-A 2026-10-07 rivet-compiled 1000 rows: 43 → 15 chunks, alloc 502 → 431 KB/page, CPU −1% (noise); Node's HTTP response corks a tick's writes into one writev either way; `early` (default): sink uncorked once 128 KiB went out — first byte = head + first slice, bodies run to completion, no event-loop yields (replaced `share` slicing 2026-10-09, TRANSPORT-R3; every ssr-bench Node lane writes through it). Uncork = the RESPONSE's own cork when it has one (Node 26.11 `write_` calls `msg.cork()`, chunked frames buffer in the response, socket corked once per cork); uncorking only the socket desyncs the counts → later frames hit an uncorked socket one write each, the socket never reaches its high-water mark, the response's `drain` never fires = stalled render (seen in Docker / Linux at 359 KB of 688 KB). ## Rules / invariants

- **Zero cost**: production bundle of every subpath is hash-pinned in `scripts/zero-cost/runtime.txt` (`runtime-hashes.mjs`: rolldown, minified, `production` condition). Any byte change in a shipped file changes a hash → intended deltas only, `sh scripts/zero-cost/check.sh --update`. Dev-only code lives behind `#dev` / `development` condition files; `DEV` must stay a `false` constant in production.
- **Pay-per-use modules**: Suspense (`dom-suspense.ts`, `server-suspense.ts`), `resource` (`dom-resource.ts`, `server-resource.ts`; nothing at import; the server resume hooks in `server-resource-slot.ts` tree-shake without a reader), spreads (`server-spread.ts`, `dom-v2-spread.ts`), the derived recorder (`server-derived.ts`, `_setDerived`) install themselves on import; `sideEffects: false` drops them when unused. Don't add top-level side effects elsewhere; don't add exports to entry files for tooling (entry bundles keep all exports).
- **Compiler ABI** (`package.json` `"rivet": { "abi": N }`): the compiler-emitted helper contract this runtime implements; `@rivetjs/compiler` `RUNTIME_ABI` (`libs/compiler/abi.ts`) must equal it and its Vite plugin fails builds/dev start on a mismatch. Bump both together on any semantic change of a compiler-called helper, marker/template/resume format (test: `libs/compiler/tests/abi.test.ts`). ABI 3 (2026-10-08): `_cond`; ABI 4 (2026-10-09): `_tx` (sole text child on a template placeholder Text); ABI 5 (2026-10-09, IMPL-SPREAD): `_attrs`, `_spread` 5th argument `exclude`. ABI 6 (2026-10-09, IMPL-RESUME): `_rRowPlan` + `For` `$rows` (server resume row plans), router `_linkHref` (compile-time bare server `<Link>`). ABI 7 (2026-10-09, IMPL-SPREAD F3): `_pm`. ABI 8 (2026-10-09, Function Bridge T2, plan `docs/design/plans/2026-10-09-function-bridge.md`): `_rMod`; later bridge tasks add thunk captures, `_rCell`, `_rBound`, `_rGroup`, `_rStorePaths`, `_rClass` under the same number.
- **Untampered built-ins required**: ordinary intrinsics are assumed (`_list` compares `Array.prototype.map`, records are never thenable); no polyfill tolerance.
- **No component runs in the browser on a resumed page** (`__componentRuns` stays unset in Playwright tests); a region is re-created, never resumed.
- Cold events replay in dispatch order (one promise chain; a hot event waits while cold ones are pending) — `resume-cold-order.test.ts` holds the keydown chunk behind the input chunk. The inline loader holds them (defaults, `live` form state) and queues them in `api.q` until the runtime starts; `dom-resume` `cold(item)` owns the chain and `on(event, hit)` runs a live event when nothing is queued and its chunks are evaluated (LOADER-DIET). Regenerate `resume-loader.min.ts` after loader edits.
