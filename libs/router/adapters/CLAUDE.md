# @rivetjs/router — adapters (`/node`, `/fetch`, `/static`, `/csr`, platform targets)

> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Deploy targets over the app handler (`createApp`). Build: `vite build` (→ `dist/client`) then `vite build --ssr` (→ `dist/server`).

## Entry points

- `/node` → `node.ts`: `start(StartOptions)` (load `dist` + serve), `serve(ServeOptions)` (any web handler), `createListener`, `closeOnSignals`, `negotiate` (br/gzip, highest q, tie → br; memoised per header string, bounded 64), `etagMatches`, `byteRange`.
- No public subpath: `build.ts` (`loadBuild`, `readManifests`), `assemble.ts`, `target-build.ts`, `pack.ts`, `files.ts`, `server-target.ts` — internal (tests import `../adapters/build.ts` / `vercel.ts` / `pack.ts` by path).
- `/fetch` → `fetch.ts`: `createFetch(entry, manifests, FetchOptions)` → `{ fetch(request, env?, ctx?) }`, `nonce()` (re-export of `shared/nonce.ts`, also used by `node.ts`). Generated `dist/server/fetch.js` exports `default` + `create(options)`.
- `/static` → `static.ts`: `prerender(PrerenderOptions)`, `prerenderBuild(dist, options)`, `fillPattern`, `hashCSP`.
- `/csr` → `csr.ts`: `shellHTML(document, { script, styles, url })` single-page shell.
- Platform targets (`rivetRouter({ adapter: name | { name, …options } })`; runtime module `create(entry, build, options)` / `start(…)`, imported by path from the generated entry):
  - `/vercel` → `vercel.ts` (Node.js function: `create` → node `createListener` request listener, `trustProxy: 1`, `idleMemory: false`, `compress` default on; `isrURL` undoes the ISR `__rivet_path` rewrite), `/vercel-edge` → `vercel-edge.ts` (`(request, context) => Response`, address `X-Real-IP`).
  - `/netlify` → `netlify.ts` (`(request, context) => Response | undefined`; address `context.ip`; `staticPaths` → `undefined` = Netlify serves the file, Edge Functions only).
  - `/cloudflare` → `cloudflare.ts` (`{ fetch(request, env, ctx) }`, address `CF-Connecting-IP`).
  - `/bun` → `bun.ts`, `/deno` → `deno.ts`: `start(entry, build, { client, port, hostname, signals, …FetchOptions })` → `Bun.serve` / `Deno.serve`; client files via `files.ts`; generated entry runs `start()` only `if (import.meta.main)`.

## Layout

- `node.ts` — Node HTTP server: static files (`<base>/assets/` immutable, br/gzip), Request/Response bridge, `/healthz` + `/readyz`, graceful drain (`grace` 10 s), `origin` / `trustProxy`, nonce per request (`shared/nonce.ts`). `reusePort` (serve option) listens with `{ reusePort: true, exclusive: true }` (each cluster worker its own `SO_REUSEPORT` socket, kernel balancing); `serve()` throws a `TypeError` for port 0 and outside Linux / FreeBSD. `start({ workers: n | "auto" })` (default 1; `"auto"` = `os.availableParallelism()`, which may count host cores in a CPU-quota container) with n > 1 dynamically imports `cluster.ts`.
- `cluster.ts` — node:cluster multi-core (loaded only with `workers` > 1). `primary(count, grace, log)`: forks the running script `count` times, resolves `{ url, workers, close }` once every worker emits `listening` (a `PrimaryServing`: `server?: undefined`, `workers: number`; `Serving` = `ServerServing | PrimaryServing`, narrow on either field; `serve()` / `worker()` return `ServerServing`; `start()` overload without `workers` or `workers: 1` returns `ServerServing`, so single-process callers keep a non-optional `server`), replaces crashed workers once all first workers listen (gives up after > 5 exits in 10 s, logged; `process.exit(1)` when none is left); a worker exiting before it listens rejects the promise and SIGTERMs the others (no replacements); relays `rivet:revalidate` IPC messages (target shape checked: `path` / `tag` strings) to the other workers; `close()` sends `rivet:close` (worker drains with its own `grace`, exits 0), SIGKILL after `grace + 2 s`. `worker(run)`: `run()` = `start({ ...options, workers: 1 })`, sets `globalThis[Symbol.for("rivet.revalidate.broadcast")]` (route-cache `revalidate()` calls it after the local drop; sends only while `process.connected`, send errors ignored) and on a relayed message calls `globalThis[Symbol.for("rivet.revalidate.local")]` (registered by `server/route-cache.ts` at load); primary `disconnect` → drain + exit. Round robin (cluster default) unless `reusePort`. Tests `tests/cluster.test.ts` (child `tests/cluster-app.ts`, `CLUSTER_MODE`): 2 pids serve, per-worker route cache, `revalidate()` reaches both, crash replaced, close exits 0; `fail-start` rejects with 2 forks only; `give-up` exits 1; `reusePort` guards.
  - Early hints (EARLY-HINTS 2026-10-12): `serve({ earlyHints: true })` puts a writer on each built Request (`Symbol.for("rivet.earlyHints")`, HTTP/1.1 clients only) → `res.writeEarlyHints({ link })` unless headers are out; the app (`createApp({ earlyHints })`) calls it before guards. `start({ earlyHints })` sets both (option for `createApp`, `true` for `serve`). Fetch `create({ earlyHints })`: `Link` header only (CDNs convert). Browsers use 103 over h2+ only: EARLY-HINTS bench (Chromium through an h2 proxy forwarding 103s, RTT delay) — FCP 420 → 320 ms (100 ms RTT, 200 ms loader), 324 → 276 (50 ms RTT), 224 = 224 (no loader); CPU 15.3 vs 15.3 µs/request in-process.
  - Route rules fast path (ROUTE-CACHE 2026-10-12): GET/HEAD after `serveFile`, before `toRequest`: `handler[Symbol.for("rivet.routeCache")]?.(method, origin, pathname, search, header)` → a fresh stored page (`server/route-cache.ts` `CachedPage`) is written like a static file: per page (WeakMap) base + page headers merged once, `If-None-Match` (`etagMatches`) / `If-Modified-Since` → 304, br (q11, text mode) / gzip (9) compressed once per page asynchronously and memoised (≥ `MIN_COMPRESS`; each copy `page.charge(bytes)` against `maxBytes`), `Vary: Accept-Encoding` on identity / encoded / 304 answers of compressible pages, `age` + `x-rivet-cache: HIT`. Stale / missing pages go the normal way (the handler's wrapper refreshes). Only `import type` from `route-cache.ts` (the module stays out of apps without rules). `start({ routeRules, routeCache, renderCache })` → `loadBuild` → `createApp`; fetch `create({ routeRules, routeCache })`; both pass their fixed `origin` as `routeCache.origin` (an explicit one wins).
  - Request URL = origin + `pathOf(req.url)`: origin-form as is (`//x` stays a path); absolute-form only for the computed origin (fixed `origin`, forwarded or Host) else 400; `*`/authority-form 400. Host (or trusted `X-Forwarded-Host`) must match `HOST` (name / IP literal + port; no userinfo, path, spaces) else 400 (`Connection: close`), before the handler and before `/healthz`.
  - Unread request body: on `res` `finish`, `drain(req)` (remove `data` listeners + `resume()`, as Node's own dump) — `Readable.toWeb` disables Node's auto-dump, so early answers (403/405/413/guard) would stall keep-alive/pipelined requests.
  - Static file streams: a client gone before / during the file (`res.destroyed`; `ERR_STREAM_UNABLE_TO_PIPE` / premature close) ends quietly — no `onError`, no 500 (test "a client that goes away mid-file").
  - Static: `.well-known/` served at the client root only (index + fs lookup; other dot segments refused); `Last-Modified`; `If-None-Match` lists/`*`/weak compare, else `If-Modified-Since` (second precision) → 304; one `Range: bytes=` → 206 identity bytes (`Accept-Ranges: bytes`, `Content-Range`), unsatisfiable → 416 `bytes */size`, several ranges / other units → 200; `If-Range` honoured only as the exact `Last-Modified` (ETag is weak).
  - Static files: `indexFiles(client)` at `createListener` (sync walk: real paths, size, mtime, `.br`/`.gz` sibling sizes; dot-named entries skipped; symlinks resolved, kept only inside the dir; cycles cut). Lookup = decoded path (same `\0` / dot-segment refusal) → key with empty segments dropped. MIME type / weak ETag / `Last-Modified` derived once per indexed entry (`metaOf`, WeakMap; `static: "fs"` per request): 0.65 µs → 7 ns per asset request. `static: "fs"` = old per-request `realpath` + `stat` (dirs that change while serving). Measured: page GET 185 → 96 µs, asset GET 270 → 141 µs (keep-alive round trip, loaded host).
  - Responses: a body complete before `setImmediate` goes out with `Content-Length`; uncompressed = its chunks written as they are (corked, no `Buffer.concat` copy), compressed = one buffer through `compressOnce`. Still pending → streamed.
  - Rendered pages (`DIRECT_BODY` on the Response, `server/body.ts`; unread body): `sendDirect` attaches a sink instead of `getReader()` — no ReadableStream reads, `Promise.race` per chunk or 64 KiB stream pauses. Complete at attach → Content-Length (one corked write). Early bytes (TRANSPORT-R3 2026-10-09): uncompressed and still rendering at attach (the renderer hands the Response out only after its first 64 KiB or a pending boundary, so status / headers are final — never before the loader) → headers + the rendered head written and the socket uncorked at once (`early`), later chunks stream straight to the response (chunked; Node corks a tick's writes; backpressure past `MAX_BUFFERED`) — no `setImmediate` hop on the uncompressed path (lead: a macrotask turn ≈ 15 µs + poll phase). The only remaining macrotask is the compressed collect below (one-call compression needs the turn). `serveResponse` non-direct bodies (endpoints) keep their `setImmediate` turn race. Writes cork the SOCKET, never the response: Node 26 `res.uncork()` uncorks the socket before writing a chunked body's buffered frames (one syscall per frame) and `res.end()` sends the chunked terminator before them; `res.uncork()` below zero breaks the count. Compressed: chunks (renderer slab views) collect until `setImmediate` (same Content-Length / one-call compression rule as above), then stream (headers, collected chunks through `compressor` + `pipeline`, later writes with backpressure past `MAX_BUFFERED` 256 KiB). Each view's `done` runs from the `res.write` callback (or after the compression copy), so the renderer reuses its slabs. Abort (`request.signal`) / response close → the next sink write throws → render ends. Body already read (copied Response) → old path. Tests: `tests/node.test.ts` "rendered pages go out directly", "a large synchronous page writes its head to the socket before the render ends".
- `uws.ts` — EXPERIMENTAL (UWS-SPIKE 2026-10-09), no subpath, no dependency: `serveUws({ handler, uws?, client?, base?, port, host, compress, origin, headers, grace, onError })` → `{ url, close }` over uWebSockets.js (module passed in or `createRequire(import.meta.url)("uWebSockets.js")` — the v20.71.0 ESM wrapper is broken). Node adapter page semantics: status/headers after the handler, Host check (400), `/healthz` `/readyz`, `DIRECT_BODY` sink (uWS copies on write → views released at once), collect until `setImmediate` → one corked `end` with Content-Length (br/gzip one call; multi-chunk = one concat copy), else chunked stream with `onWritable` backpressure (uWS buffers every write; sink waits after a `false`). Compressed streams: a chunk's `done` runs from the Transform's write callback (zlib reads it after `write` returns: releasing earlier let the renderer overwrite the slab → corrupt br/gzip output); uWS backpressure pauses the compressor's output until `onWritable`, its input fills and the sink waits for `drain` (bounded buffering); abort destroys the Transform (pending callbacks release their chunks). Tests: `tests/uws/adapter.ts` (`node --test` inside the uws image — not in the vitest project: exact decoded bytes over 4 KiB views of 2 reused slabs, paused reader stops the renderer, abort mid-stream releases every chunk; br / gzip / identity; watched failing on the pre-fix adapter). `onAborted` → `request.signal` abort + next sink write throws, error before headers → 500, after → connection closed. Request data read synchronously (uWS request is stack-allocated); bodies via `onData` (copied). Gaps: no trustProxy, static files read into memory at start (no ranges / conditional GET / precompressed), no `idleMemory`. No committed consumer (UWS-SPIKE ssr-bench lanes stay out of tree). Pilot 2026-10-09 (Docker 1 CPU, 1 repeat, uncompressed): CPU/page 1.08–1.31× vs the node adapter on the same image at 0 / 100 rows c1 / c10 — below the 1.3× adoption bar; not a default candidate.
- `idle-memory.ts` — Node-only (`node:v8`, `node:vm`), imported by `node.ts`; `idleMemory(inflight, options)` → `{ request, idle, stop }`, `idleMemorySupported()` (Node, not Bun/Deno). Works around V8 13.6/14.6: memory reducer needs young && old && embedder (cppgc) rates "low", and `ComputeMutatorUtilizationImpl` returns 0 for a rate of exactly 0 → a process with no cppgc allocations is "high alloc" forever; only the 100 s `WatchdogGC` shrinks it. Fix = one `new vm.Script("")` (56-byte cppgc `ContextifyScript`; `vm` is loaded at Node boot anyway) once idle: the next reducer tick sees a decayed tiny non-zero rate → "low" → 2–3 shrinking GCs.
  - Listener: `memory?.request()` after `inflight++` (counter), `memory?.idle()` when `inflight` hits 0, `memory?.stop()` in `drain()`. `/healthz` `/readyz` are not traffic. `ServeOptions.idleMemory: false` = no controller.
  - Controller: one unref'd timer at most. `delay` 1 s after the last request (requests in between → another full delay; busy at fire time → no re-arm, next `idle()` arms); pressure = committed (`total_heap_size`) ≥ max(1.1 × settled, settled + 10 MiB) (V8's own kDone re-arm rule; settled = committed at listener creation, after a shrink, or after giving up); nudge, re-check after `recheck` 17 s (two 8 s reducer ticks + slack); stop when committed fell ≥ 10 % (settle), no pressure, a request arrived, or after `attempts` 5 (settle at current: live set grew). 5 × 17 s stays inside the ~110 s window where young/old smoothed rates are still non-zero (after that they underflow to 0 and only the watchdog helps).
  - Measured 2026-10-07 (Docker node:24.14.1, ssr-bench rivet-resume, 10 s 5000-row burst → idle, RssAnon, 3 paired runs): off 129–180 MiB held until t≈110 s (watchdog) → 56–78; on 127–161 → 56–70 at t=15 s. Bench table: commit message / `apps/ssr-bench/CLAUDE.md`.
- `build.ts` — Node-only: `readManifests(dist)` (`.vite/manifest.json`, resume manifest, `rivet-route-css.json`, `rivet-inline-css.json` → `BuildManifests.inlineStyles` (`InlineStyleManifest`) → `createApp({ inlineStyles })`, fetch / platform targets inline it with the rest; per locale), `loadBuild(dist, config, options)` imports `server/entry.server.js`.
- `assemble.ts` — web-standard: `assemble(entry, manifests, config)` → handler (shared by `loadBuild` and fetch). Global styles = CSS of the Vite manifest's app entries, not of compiler resume chunks (`src` `\0rivet-resume-chunk:…`: their CSS is per route, `build/route-css.ts`).
- `fetch.ts` — web-standard runtime of the fetch adapter.
- `target-build.ts` — build side of every target (was `fetch-build.ts`): option types (`AdapterOptions` union, `BUILD_ONLY` keys never serialized), `adapterOptions` (name → options, validation), `targetBuildConfig` (2nd SSR entry `dist/server/<ENTRY_FILE>.js`: fetch / vercel / netlify / worker / bun / deno; `ssr.noExternal: true`, `copyPublicDir: false`), `targetEntryPlugin` (generated entry: server entry + inlined manifests + build-time defaults → runtime `create`/`start`; `closeBundle` of the server build → `pack.ts` for vercel / netlify / cloudflare). Used by `build/vite.ts`.
- `pack.ts` — Node-only packaging after `vite build --ssr` (contract URLs in its header, verified 2026-10-08). Copies `dist/client` (no dot-named entries but `.well-known`), prerenders (`static.ts` `prerender`, hash CSP) routes with `prerender === true` (all in `mode: "static"`; server mode drops the 404 page) by importing a temp copy of `dist/server` (Node caches modules by path: chunks import the entry back, so a rebuilt `dist/server` in the same process would load stale chunks).
  - Vercel (Build Output API v3): `.vercel/output/` (wiped) = `config.json` (`version: 3`; routes: `^<base>/assets/.+$` immutable `continue`, `handle: filesystem`, ISR rewrites, catch-all → `/_render`; static mode: `handle: error` → `404.html`; `overrides` map prerendered `a/index.html` → `a`), `static/<base>/`, `functions/_render.func/` (copy of `dist/server` + `package.json` `type: module` + `.vc-config.json`: Node `nodejs<24>.x` `launcherType: Nodejs` `shouldAddHelpers: false` `supportsResponseStreaming: true`; edge `runtime: edge` `entrypoint`). ISR (`isr: { expiration }`, Node only): `functions/_isr/<path>.func` symlink → `../_render.func` + `.prerender-config.json` (`allowQuery: ["__rivet_path", "_rivet"]`, `passQuery`), route `^<path>/?$` → `/_isr/<path>?__rivet_path=<path>`; no static file.
  - Netlify (Frameworks API): publish dir `dist/netlify/<base>` (user sets `publish` in `netlify.toml`), `.netlify/v1/config.json` (`headers` immutable `<base>/assets/*`), function `.netlify/v1/functions/rivet-server/` (copy + `package.json` + `rivet-server.mjs`: re-export + literal `config` `{ path: "/*", preferStatic, nodeBundler: "none", includedFiles }`) or edge `.netlify/v1/edge-functions/rivet-server/rivet-server.js` (`create({ staticPaths })` = every published file + page dir aliases; `excludedPath` assets). Only `rivet-server` dirs + `config.json` are ours (Netlify CLI state stays).
  - Cloudflare: `dist/cloudflare/{wrangler.json, static/<base>/, static/_headers}` + `.wrangler/deploy/config.json` (`configPath`, Wrangler's redirected config). `wrangler.json`: name (package name), `COMPATIBILITY_DATE`, `WORKER_FLAGS` (`nodejs_als` + `no_nodejs_compat` + `no_nodejs_compat_v2`), project `wrangler.json(c)` merged (`stripJSONC`; `wrangler.toml` warned, not merged), `options.wrangler`, then forced `main` `../server/worker.js`, `base_dir`, `no_bundle` + `find_additional_modules` + ESModule rule (rollup chunks uploaded as is), `assets.directory` + `html_handling` (`drop-trailing-slash`, `force-` for `trailingSlash: "always"`), static mode: no `main`, `not_found_handling: "404-page"`.
- `files.ts` — Bun/Deno static index (once at start; dot segments except `.well-known` skipped; `.br`/`.gz` siblings; weak ETag + 304; immutable prefixes = each client build's `assets/`; `a/index.html` / `a.html` aliases at `/a`, `/a/` except 404/200 pages). `server-target.ts` — `ServerTargetOptions` (`client`, `port` `$PORT`/3000, `hostname` `$HOST`/`0.0.0.0`, `signals`), `immutableOf`.
- `static.ts` — prerender through the handler: static routes + `serverEntries()`, two page paths equal ignoring letter case (decoded, below the base) = build error before the second is written (one file on macOS/Windows/case-insensitive hosts: the later page silently replaced the earlier), `_data.json` beside each page — written after every page rendered, and only when some page resumes (`<script type="rivet/state"`, `report.resumes`) or a CSR shell route exists (zero-JS sites get none; per route they stay: a resumed page's router may navigate anywhere) —, `prune` (`prerenderBuild` default true): no page resumes + no shell → deletes `.vite/manifest.json` chunks outside the static/dynamic import closure of the pages' `<script src>` / modulepreload URLs plus every `*.deps.js` (`report.pruned`; emptied dirs removed), origin: unset → placeholder `http://localhost` for the synthetic requests (state / data URLs are origin-relative anyway: runtime `ResumableOptions.origin`, router passes `input.url.origin`) and a state script or `_data.json` still holding it (a URL *string* from `url.href`) = build error naming the value; CSR `200.html` shell for the rest, per-page hash `<meta>` CSP (placed after a leading `<meta charset>` + `<meta name=viewport>`, else right after `<head>`; `hashCSP(html, { trustedTypes, directives })`; hashes inline classic/module scripts and `type="speculationrules"` (document prefetch rules), and with `directives` every `<style>` body into a `style-src` / `style-src-elem` they set (`cspPolicy` `styles`), `cspPolicy` from `shared/csp-directives.ts`; pages without inline scripts get one only when `directives` given; `prerender` validates `csp` before rendering).
- `csr.ts` — shell for `mode: "csr"` (no server; no `.server.ts`); script URL escaped with `@rivetjs/runtime/escape` `escapeAttribute`.

## Rules / invariants

- `fetch.ts` / `assemble.ts` stay web-standard (no `fs`/`path`, no runtime `import()` of file paths). Only node import reachable at runtime: `node:async_hooks` (resume state) → Workers need `nodejs_compat`.
- Same pages on node and fetch: identical HTML, strict nonce CSP (16-byte base64), `nosniff` + `Referrer-Policy: strict-origin-when-cross-origin` defaults (header names case-insensitive: a `headers` option replaces the default of that name, a handler response's own header wins; node skips base entries the response has, fetch adds only missing ones), CSRF, `maxBody`, data endpoint, 404/500.
- Origin for CSRF/redirect checks: node `origin` (fixed) or `trustProxy`; fetch: request URL or `origin`. Never default `trustProxy` on.
  - `trustProxy`: `true`/`1` = one hop, `n` = n hops, `(address, hop) => boolean` per hop from the socket peer inward. Client address = chain (`X-Forwarded-For` entries + peer) at index `len-1-trusted` (right to left: client-sent entries never win); `X-Forwarded-Proto/Host` at index `len-trusted` (clamped to 0). Predicate with untrusted peer = forwarded headers ignored. Breaking 2026-10: `true` used the leftmost value.
- Static `trailingSlash` (`prerender({ trailingSlash })`; `prerenderBuild` reads `entry.trailingSlash`): pages requested at the canonical URL (`report.pages` lists those); `never` → `a.html`, else `a/index.html`; `_data.json` always `a/_data.json` (client `dataURL`). Root → `index.html`.
- Static: a route not prerendered (dynamic without `prerender`/`serverEntries`) whose own module **or any layout** has `serverLoad`/`serverGuard` throws (needs a server; the CSR shell would skip them). Files written relative to `base`.
- CSP option threads through unchanged: `start({ csp })` / `loadBuild` / fetch `create({ csp })` → `createApp`; static uses `hashCSP`.
- `preload` (`AppConfig["preload"]`, background prefetch budget + `lean` pages) threads the same way: `start` / `createFetch` / vercel / `loadBuild` / `prerenderBuild` → `createApp`. `rivetRouter({ preload: { background } })` sets the app's `background` default (generated server entry `preloadBackground`, used by dev and every adapter unless their `preload.background` is given); dev manifests have no chunk sizes, so dev pages still plan every below-fold chunk viewport-only.
- Fetch: client build must run before `vite build --ssr` (manifests inlined at build time). Static assets are the platform's; no compression, no `/healthz`.
- Platform targets: zero-cost — runtime modules load only from their generated entry; `vite.ts` imports `target-build.ts` (build side), `pack.ts` loads lazily in `closeBundle`. Node adapter path unchanged. Vercel Node.js reuses `createListener` (direct page bodies), every other target the fetch adapter (web streams).
- Platform data: `event.platform.env` = Workers bindings only; `event.platform.ctx` = Netlify context / Vercel Edge context / Workers ctx / Bun server / Deno serve info; `clientAddress` per platform header/context (Vercel `X-Forwarded-For` via `trustProxy: 1`, edge `X-Real-IP`, Netlify `context.ip`, Workers `CF-Connecting-IP`, Bun `requestIP`, Deno `remoteAddr`).
- Buffer slabs off Node: every in-place `utf8Write` call (`server/render.ts` `BodyWriter`, runtime `server.ts` `putLong`, `server-bytes.ts` `putText`) passes an explicit length — workerd's `nodejs_compat` `Buffer` polyfill throws `RangeError ERR_OUT_OF_RANGE` on `utf8Write(text, offset)` (fixed 2026-10-08, verified with `wrangler dev --local` + `nodejs_compat`). `WORKER_FLAGS` still keeps only `nodejs_als` (smallest Node layer); user configs may add `nodejs_compat`.

## Gotchas

- `node.ts`, `static.ts`, `csr.ts` are referenced by path in `apps/docs/api.config.ts`.
- Generated entries reference runtime modules as `new URL("./x.ts", import.meta.url)` (package build rewrites to `.js`): keep that inline form in `target-build.ts`.
- `deploy.test.ts` imports built entries from temp copies (`load`) for the same module-cache reason as `pack.ts`.
- Behind a TLS proxy without `origin`/`trustProxy`, every POST is rejected 403 (origin mismatch).
- i18n builds: per-locale `client/<locale>/` dirs; `start({ locales })` marks each `assets/` immutable.
