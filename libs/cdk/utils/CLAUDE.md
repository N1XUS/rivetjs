## Rules / invariants
- `RouterContext` = `createContext(nativeRouter)`
- `globalDOMProps(props, OWNED)`: forwards mouse/touch/pointer/scroll/wheel/animation/transition events (+ Capture) and `dir`/`lang`/`hidden`/`inert`/`translate`; keyboard/focus events belong to focusable components, text-input events to the input (`textInputDOMProps`), drag/media left out (as upstream); OWNED events are chained from the component's own handler
- `mergeProps` / `chain` / `mergeRefs`: one implementation in `../interactions/merge-props.tsx` (RA rules; resume-compiled so chained handlers resume when their inputs do; aria id lists are not joined)
- `useDescription`, `useFormReset`, DOM helpers, `useSlotId`: browser only, call from client effects / handlers; server markup renders its own description element
- id bookkeeping (`updaters`) browser-only, never serialized; dead `WeakRef`s pruned lazily (a list at power-of-two lengths ≥ 8, the whole map when it doubles past 1024 ids) or by `releaseId` — no `FinalizationRegistry` (a registration per reactive id cost ~1 µs + GC weak-cell work: TextField 1000 mounts part of −6%, HOTPATH 2026-10-09)
- `RouterProvider` children: plain (lazy slot, `renderSlot`) or `{() => ...}`; `navigate`/`useHref` inline arrows or local functions (resumable). `Router` must stay plain data (no methods): handlers capture it
- `useSlotId` on server returns `id`
- package-wide rules: [../CLAUDE.md](../CLAUDE.md)

## Gotchas
