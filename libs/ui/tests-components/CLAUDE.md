# libs/ui/tests-components

> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Browser tests for `@rivetjs/ui`: resumed story app (production build + node adapter + Chromium), Tailwind v4 + vendored `@heroui/styles`.

`removed-region.test.ts` also checks showcase-auth's computed password type: repeated show/hide toggles update both forms after resume and after the form step is removed and mounted again, keeping the password value.

## Runner

- vitest project `ui-components` (root `vitest.config.ts`): `libs/ui/tests-components/*.test.ts`, `fileParallelism: false` (one build + Chromium, one file at a time). `nx run ui:test` runs it after `ui` (both `--maxWorkers=2`, through `scripts/vitest-seq.ts`; `--shard=i/n` = CI shard of both projects' files, balanced by `scripts/ci/test-weights.json`).

## Harness (same API as `libs/cdk/tests-components`)

- `harness.ts`: cdk's copy (Chromium args `--use-mock-keychain --password-store=basic`) + ui helpers. `stories({ preload? })` defaults to `{ lean: true }` (no fetch-ahead, M6-CUT); `navbar` / `scroll-area` pass `{}` (they measure fetch-ahead). `stories()` skips the build when `inject("uiStoriesDist")` (set by `global-setup.ts`, the project's vitest `globalSetup`: one `buildApp()` per run, CI-TIME 2026-10-21) is its `dist`, else builds once per process (`app/serve.ts` `buildApp`; the fuzz project), `start({ dist, port: 0 })`, one headless Chromium; `watch(page)` → `{ scripts, errors }` (script request pathnames, page errors); chunk checks read the build manifest, never file names (route chunks by default: `resume-<route file>-…`, merged shared chunks `rivet-merge-…`): `chunksOf(symbolIdRegex)` (`.vite/rivet-resume.json` `symbols`, ids `<module>#<Component>$<hash>`, library modules `@rivetjs/ui/<path>` / `@rivetjs/cdk/<path>`), `codeOf(regex)` = those chunks + the shared chunks only they import, `among(scripts, chunks)` (a `.deps.js` list counts as its chunk), `scriptsOf(scripts, regex)`; runtime chunks = the static closure of the resume runtime entry and of the chunks holding the router App's symbols (`resume-route_main` in route mode, layouts included; `resume-App` with component chunks) + the resume loader module (LOADER-DIET 2026-10-12, evaluates no component code); `nonRuntimeScripts(seen)` = every other script (ui components, `dom.*` symbols, route chunks) — "no JS before interaction" asserts it is `[]` after `networkidle`, and a positive control asserts it is non-empty after an interaction (masking caveat: page code the merge budget puts into the App's closure counts as runtime); `libraryScripts` (chunks holding ui / cdk symbols) / `focused` kept for parity. `traceFade(page, selector, ms)` samples per frame (opacity, `data-entering` / `data-exiting`, running animations, `backdrop-filter` blur px; `now()` = trace time before closing) + `assertFades(samples, closedAt, label)` (fade in to opacity 1, fade out while mounted, then unmounted).
- `app/serve.ts`: cdk's copy; `dist = app/ + (STORIES_DIST ?? "dist")`; manual serving `PORT` default 4330 (4320–4326 are the docs servers).

Every wave-1 component reads props live (`../tests/live-props-wave1.test.tsx`); element-picking props (Separator `orientation`, Typography `type`) still need a re-created part.
- Former runtime bug: a `_spread` update re-ran the `children` slot when another key changed (`dom.*` children re-created on every accessor-prop change) — fixed in runtime commit "fix(runtime): spread re-inserts children only when `children` changes"; `resume.test.ts` and `../tests/dom.test.tsx` assert node identity.
- First mouse click flushes one task later (root CLAUDE.md): wait (`waitForFunction` / `waitForSelector`) before reading the DOM after a `page.click`. A re-created empty element is not "visible": `waitForSelector(…, { state: "attached" })`.
- `app/.gitignore` ignores `dist-*/` (`STORIES_DIST` scratch builds) and the generated visual routes / demo copies (`src/routes/visual/`, `src/visual/`).
- `parity-counts.json` (identity lane): test cases per file of cdk / cdk-browser / cdk-components / ui / ui-components (`node scripts/size-report/parity-counts.mjs [--check]`: a `-t` run matching no test name, JSON reporter; `vitest list` parses `.tsx` without the Rivet loader); counts never drop without a listed reason.
- Client-created kit `Icon` svgs carry a `<!---->` child anchor the server markup lacks (comment only, same elements): compare markup with comments dropped (`wave1.test.ts` `snapshot`).
- Two instances of a cdk field get different generated ids (`id` / `for` / `aria-*` `rv…`): mask them before comparing instances.
