## Geometry (concentric radii, identity T5, TW-123–TW-132)

- Golden rule: a rounded child inset `p` (padding + border) from a parent of radius `R` has `max(--r-min, R − p)` (`--r-min` = `--radius-sm`, 4 px, `themes/shared/theme.css`). Pills (Button, Chip, Tag, Tab) are exempt; `.button:where([data-radius="concentric"])` opts in.
- A padded surface declares `--r-inner` for what it holds (popover lists, `.popover__dialog`, `.modal__dialog`, color picker / date picker popovers); consumers read `border-radius: var(--r-inner, <HeroUI default>)`. A nestable surface (Card) never declares `--r-inner` on itself (a custom property cannot read its inherited self): `.card` takes `--r-card: var(--r-inner, 24px)`, `.card > :not(.card)` sets the next `--r-inner`. A deeper level uses its own name (`--r-year` = year grid). Lists reset `--r-inner: initial` so a Card's value never leaks into list items outside popovers.
- Test: `libs/ui/tests-components/geometry.test.ts` (Chromium, `/visual/*` + `/geometry` routes) asserts the formula on each nest.

## Spacing, hit targets, density (identity T7, TW-136–TW-139)

- Scale `--space-1…8` = 4 / 6 / 8 / 12 / 16 / 24 / 36 / 52 px (`themes/shared/theme.css`; Tailwind units 1 / 1.5 / 2 / 3 / 4 / 6 / 9 / 13). `libs/ui/tests/spacing.test.ts`: every padding / gap utility on an `@apply` line of `components/*.css` is a step or in `EXCEPTIONS` (file → utilities, grouped by reason); new off-scale values and stale exceptions fail. Ratios: pills 2 : 1 (Button lg 20 / 10, Chip 8 / 4, Tag 8 / 4 + 12 / 6), fields 1.5 : 1, list items 1.33 : 1.
- `touch-target` (`utilities/index.css`): `::after` = host box grown by `max(0, (target − size) / 2)` per side; target `--touch-target` 24 px, 44 px under `(pointer: coarse)`. Host must be positioned and must not clip (`overflow: hidden` controls → put it on the `__content` label instead: checkbox / radio / switch). Uses: `__content` of checkbox / radio / switch, `.close-button` (Tag remove, Toast close, search clear), `.tag__remove-button`, `.carousel__dot`.
- Density: `data-density="compact"` on an ancestor → one step down via `<block>:where([data-density="compact"] *):not(:where([data-density="comfortable"] *))` rules (specificity of the block class) at the end of button / input / textarea / select / input-group / list-box-item / menu-item; any `data-density="comfortable"` ancestor restores the default (also one above the compact one: put comfortable only inside compact). Selector kept short: +~0.1 k brotli per page. Test: `tests-components/spacing.test.ts` (`/spacing` route; fine + `hasTouch` coarse).

## Icons (identity T8, TW-140)

- Icon box = f(host text): 12 → 14 (12 inside a sm Tag), 14 → 16, 16 → 20; square, `shrink-0`, no margins. Stroke in lucide units on the svg (CSS `stroke-width` beats `Icon`'s presentation attribute): 16 → 2 (default), 20 → 1.75, 14 → 3.43 / 12 → 4 (= 2 px, `absoluteStrokeWidth`). Set in each component file (docs sites load no base CSS), no kit change. Test: `tests-components/icons.test.ts` (`/visual/*` + `/icons` route: size, margins, computed stroke).

## Motion, field rhythm, RTL (identity T9, TW-141–TW-143)

- Durations only via `var(--duration-fast | base | slow)` (120 / 180 / 260 ms) or `duration-(--duration-*)`; `--ease-smooth` = `cubic-bezier(0.2, 0, 0, 1)`. `libs/ui/tests/motion-tokens.test.ts` fails on a literal duration not in its `EXCEPTIONS` (reasons) and on stale exceptions. `@rivetjs/motion` reads the same tokens.
- Fields: root `gap: var(--field-gap-help)` (4), label adds `--field-gap-label − --field-gap-help` (`label.css`, roots listed there; a new field root → add it to that `:where()` list), groups `--field-gap-group` (16).
- RTL: centre with `left-1/2 -translate-x-1/2` (direction-neutral), never `start-1/2` + a physical translate; physical 1 px nudges get an `rtl:` mirror.

## Look presets (TW-148)

- Shape is themeable: `--border-width`, `--field-border-width`, `--surface-shadow`, `--overlay-shadow`, `--field-shadow`, `--radius` / `--field-radius`, `--surface-backdrop` (`.card` `backdrop-filter`, default `none`). A preset sets them through `overrides` (`src/theme/presets.ts`); `themes/presets.css` declares all of them per preset so swapping back resets them. A new shape token → read it with a `none` / neutral fallback in the component file, add it to `SHAPE` in `../scripts/gen-themes.ts`.

## Brand (identity T11, TW-144)

- Logo gradient only on brand surfaces: `.button--brand` (deep stops `--rivet-blue → purple`, white label; every stop is a `CONTRAST_PAIRS` entry via `src/theme/contrast.ts` `BRAND_STOPS`). Hover / press shade = `--button-shade` layer, not a second gradient. `--rivet-*` unset (theme other than Rivet) → accent fill. Never on focus, text or state colours.
