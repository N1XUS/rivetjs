# Docs site (Phase 0 spikes + Phase 1 MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven-development) to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** `apps/docs`: the Rivet documentation site, built with Rivet (file routes, router `mode: "static"`, `prerenderBuild`), Tailwind, Markdown content, live examples in cross-origin iframes, StackBlitz export, starter templates, Pagefind search, generated API reference. Content for merged features; stubs for features in flight.

**Spec:** [docs/design/specs/2026-10-03-docs-site-design.md](../specs/2026-10-03-docs-site-design.md) (Decisions override).

**Tech stack:** TypeScript (Node 24 type stripping), Vite 8.3.2, `@rivetjs/router/vite` (static), Tailwind 4.3.3, unified/remark-parse/remark-gfm/remark-directive, Shiki 4, Pagefind 1.5, TypeDoc 0.28, node:test, Playwright Chromium.

## Decisions (spec vs code)

- **Content routes (D1/D2 missing):** neither router `.md` page extensions nor programmatic routes. The content tool generates real `.tsx` route modules from `content/**.md` into `src/routes/(docs)/` (path-less group; gitignored) before the router scans. Same result as D1 (real routes, per-page chunks, codegen types), no framework change. Dev: the docs Vite plugin regenerates on `.md` change.
- **Text in generated JSX:** JSX text with entities (`&lt;`, `&#123;`, `&#10;`), not `{"…"}` (string expressions are dynamic children, not hoisted). Spike: entities decode to static fragments; code lines stay one source line so `&#10;` keeps newlines.
- **MPA (Q2, D7 missing):** every internal link carries `data-rivet-reload` (the router's per-link opt-out), so navigations are full loads; Speculation Rules prerender on hover, CSS cross-document view transitions. The router's eager click-interceptor chunk still loads after first paint (D7) — measured and reported.
- **Three columns without slots (D12):** the root layout renders the top bar; each page renders `<DocPage>` (sidebar + article + TOC + prev/next), so nav highlighting is static per page (no URL signal reads, no resume state).
- **Examples base path (D6 missing):** examples build with Vite `base: "/<id>/"` (resume manifest and assets honour it); the docs tool wires `createApp` itself with base-prefixed stylesheets (instead of `loadBuild`, which assumes `/`). Examples are single-page (routes match `/`); multi-page examples show Code + StackBlitz only.
- **Example tabs:** CSS radio-group tabs (`:has(:checked)`), reset = link targeting the iframe name, width toggle = checkbox; works without JS. Copy buttons: resumable handler reading the DOM (no captured code strings in state).
- **StackBlitz:** zero-JS form POST to `https://stackblitz.com/run` (files inline as hidden inputs). Packages are unpublished (D19): projects pin `site.packageVersion` (`experimental`); the frame says installs work once packages are on npm. GitHub mirror links later (release).
- **Starters:** `templates/starter-static`, `templates/starter-server`, `templates/starter-minimal`; example template = starter-static minus its routes.
- **Search:** Pagefind index over `dist/client` after prerender. Dialog = Rivet component mounted from a dynamic import in the search button handler (code loads on interaction); `/` and Ctrl/Cmd-K via `clientEvent(document, "keydown")`. Excerpts split on `<mark>` into JSX (no raw HTML).
- **API reference:** TypeDoc JSON (spike S5: 0.5 s for 3 entries) → `tools/api.ts` normalizer → `src/generated/api.json` (committed snapshot) → `api/[...symbol].tsx` + `.server.ts` `entries()`.
- **Separate example origin (Q3):** `site.examplesOrigin` (prod `https://examples.<domain>`); local preview serves `dist/client` on :4321 and `dist/examples` on :4322 (different origins).
- **Deferred (Phase 2+):** Vale/readability lint, snippet typechecking of fenced blocks, Lighthouse CI target, mirror repo, `llms.txt`, errors catalogue (D14), axe, visual regression, versioning.
