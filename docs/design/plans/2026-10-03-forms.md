# Forms implementation plan (`@rivetjs/forms`)

**Goal:** typed, resumable, progressively enhanced forms on Standard Schema + router actions; opt-in layers (scope, wizard + DraftStore, autosave, errors, async field checks, arrays, files, CSRF token).

**Spec:** [forms design](../specs/2026-10-03-forms-design.md). "Decisions (user, 2026-10-03)" override earlier sections; open questions = recommended (a); CSRF: reject POST with neither Origin nor Sec-Fetch-Site in production (403).

**Architecture:** definition (module scope, never serialized) + store (plain object of signals/literals, serialized when captured) + native DOM inputs (`name` = dotted path, DOM owns values) + delegated handlers (`onInput`/`onFocusOut`/`onSubmit` on `<form>`) + `action(def, fn)` router action. Layers are separate package entries; zero bytes unless imported.

## Constraints

- Zero cost: runtime/reactivity bundle hashes identical (rd gate), ssr-bench lanes identical, oracle 227/227, typecheck, all nx tests.
- No runtime/compiler JS changes. Type-only `jsx-runtime.ts` addition allowed (`onFocusOut`/`onFocusIn`; erased).
- Router: server-side changes only; client JS of router apps byte-identical (no `client/index.ts` code in existing apps' graphs). Verified by playground client build hashes before/after.
- Runtime browser router `navigate()` returns early for an identical href → same-URL "revalidate" re-render impossible without a runtime change → deferred (report).
- No i18n dependency: issues = `{ key, params?, message? }`; translate via optional `format` function args/props.
- Rust untouched.

## Deferred / out of scope (report)

- Same-URL route revalidation after an `ok` action (runtime `navigate` identical-href early return); single-flight `data` in JSON responses therefore not emitted.
- Automatic per-render form id ordinal (needs request-scoped state); explicit `id` option instead.
- `<title>` "Error:" prefix on failed no-JS POST (head runs without the action result).
- Streaming multipart, constraint derivation, `name` attribute type checks, module-ref resume entries (P3 of spec).
