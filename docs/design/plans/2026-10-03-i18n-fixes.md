# i18n fixes (plan)

Fixes for the limits in [docs/guides/i18n.md](../../guides/i18n.md#limits) and the spec's open questions ([spec](../specs/2026-10-03-i18n-design.md)). Each task: failing test → fix → own commit.

## 1. Error pages in the request locale
- Test (`libs/router/tests/i18n.test.ts`): guard sets `locals.locale = "de"`, loader throws 404 → error page renders variant `de`, `de` manifest, `<html lang="de">`. Unmatched URL `/de/nope` → `de` via `i18n.resolve`.
- `ErrorInput.locals` (request locals when guards ran; `{}` for unmatched URLs). `createApp` `renderError` passes them to `respond`.
- `AppConfig.i18n.resolve?(request)`: locale for error pages without `locals.locale` (unmatched URLs, guard failures before the locale settled). Default: first path segment naming a locale.
- `@rivetjs/i18n/router`: `errorLocale(config)` → resolver (url prefix map, cookie, Accept-Language). `loadBuild`/`start`/`prerenderBuild` accept `localeOf`.

## 2. Unprefixed deep links
- Tests (`libs/i18n/tests/router.test.ts`):
  - `as-needed`, `/cart`, Accept-Language `de` → 302 `/de/cart` (query kept), `Vary: cookie, accept-language`.
  - cookie `en` (default) + Accept-Language `de` → no redirect (explicit choice).
  - `Sec-Fetch-Site: same-origin` → no redirect (user clicked an unprefixed link: switcher to the default locale).
  - `always`, `/cart`, nothing preferred → 302 `/en/cart`; same-origin too.
  - Prefixed URLs never redirect → no loops.
- Guard: one rule for root and deep links.

## 3. Tags inside plural/select cases (Rust)
- Tests (`libs/compiler/tests`): server + DOM output for `{n, plural, one {<b>#</b> item} other {<b>#</b> items}}`, rendered HTML per locale; select case with a param tag.
- `compile.rs`: a case with tags lowers to a nested template (server `template` record, DOM `template()` spec); cases without tags stay strings. Formatter slot value = case result (string or template).
- Non-JSX positions keep the diagnostic.
- Build: copy of `build.sh` with volumes `rivet-i18nfix-*`; merge `perf/ssr-beat-razor` again before finishing; rebuild wasm from merged source.

## 4. Dev: per-locale client modules
- Test (`libs/i18n/tests/vite.test.ts`): dev transform of a module importing `t` with `?rivet-locale=de` → `de` text; without → default.
- Plugin (dev only): `transformIndexHtml`/`resolveId` cannot see the request locale → module URLs carry `?rivet-locale=<l>`; `configureServer` middleware rewrites the dev entry script URL by the page's locale; compile options take variant from the id's query. Production unchanged.

## 5. Non-i18n SSR cost
- Microbenchmark ≤60 s CPU: ssr-bench Rivet fixture render, runtime at `13d9b67` vs HEAD.
- >1 % slower → module flag `hasVariants` set by `_variants` / `_variantValue`; visit skips variant checks when unset.
