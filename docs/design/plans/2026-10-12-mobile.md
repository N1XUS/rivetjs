# `@rivetjs/mobile` (Ionic alternative) Implementation Plan

> **Priority: later (user 2026-10-12: "mobile framework is not the priority").** Parked; no task starts without a new GO.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- One Rivet codebase → mobile web, PWA, iOS / Android via a Capacitor 8 shell.
- Native-feeling chrome (stacks, tabs, sheets, gestures, ios / md modes) on cdk / ui / motion.
- Prerendered + resumed first screen; pushed screens client-rendered; 0 B for apps that never import it.

**Architecture:**
- `libs/mobile` = `@rivetjs/mobile` (styled chrome, modes, native adapters, Vite plugin, SW) → `@rivetjs/ui` → `@rivetjs/cdk` (new headless modules: `nav-stack`, `swipe-back`, `item-swipe`, `pull-refresh`, `infinite-scroll`, `keyboard-inset`, `large-title`; gesture arbiter in `cdk/motion`) → `@rivetjs/motion` / `@rivetjs/kit` / `@rivetjs/router/client`.
- Markup mode-independent; `data-mode` + CSS layer + runtime flags.
- Router static mode + `mobile({ target: "app" })` → Capacitor `webDir`.

**Tech Stack:** TypeScript (Node 26, vitest node + Chromium projects, resume harness `libs/runtime/tests/resume/harness.ts`), Vite 8.3, optional peers `@capacitor/core` `>=8.0.0 <9` + official plugins (`latest-8`), iOS Simulator tool for WKWebView checks.

**Spec:** [`docs/design/specs/2026-10-12-mobile-design.md`](../specs/2026-10-12-mobile-design.md) (§ numbers below; Q1–Q4 asked at GO).

## Global Constraints

- **Zero-cost:** every `@rivetjs/mobile/*` subpath independently tree-shakeable, `sideEffects: false`; no barrel; `native/*` never imports `@capacitor/*` on the web path (dynamic import behind `isNativePlatform()`); existing packages' zero-cost hashes unchanged unless a task lists an intended delta (`scripts/zero-cost/check.sh`, report own lines, never `--update` others').
- **Perf first:** every task records measured bytes (min / br) and, where relevant, frame / ms numbers in the commit body; per-subpath budgets from spec §4 enforced in `size-report` from T3 on. Land every behaviour-identical non-regression (no threshold).
- **Resumability** (`docs/guides/resumability.md`): handlers inline arrows / local consts; closed overlay children = render functions; `.ts` never imports `@rivetjs/runtime/dom`; gesture engines write transforms outside `_dispatch` batching.
- **Live props** on every component prop unless documented in `libs/mobile/CLAUDE.md`.
- **Icons:** lucide via `@rivetjs/kit/icon` only; never invented SVG paths, never UTF glyphs.
- **cdk headless:** default `rv-*` classes + `data-*` state; behaviour styles inline from JS; overlays on the div overlay layer (no native `dialog` / `popover`). New cdk modules are Rivet-authored (clean-room: Ionic / Framework7 public docs only), each with CLAUDE.md + tests.
- **No Rust edits** expected; if needed: patch file to the orchestrator queue (`PATCH READY`).
- **RAM / CPU** (`$S/perf/IMPL-COMMON.md`, binding; `S=/private/tmp/claude-501/-Users-denisseverin-Projects-claude-test-rivet/d5c17ad1-df18-48dc-b37c-7b09decaac8e/scratchpad`): heavy commands via `bash $S/heavy.sh …` (**2 slots**); vitest `--maxWorkers=1`; ≤ 3 GB peak RSS per process tree (native incl.); no browser test project while another lane's Chromium runs; timed runs under `bash $S/perf/bench-lock.sh acquire MOBILE "<purpose>"` + release trap; no long-running dev servers (start → check → kill in one command).
- **Downloads:** ask in chat before every `npm install` of a new dependency (Capacitor packages, Ionic starters for the bench) — name, source, size.
- Env: `export PATH=/Users/denisseverin/.nvm/versions/node/v26.5.1/bin:$PATH`; zsh; `NX_DAEMON=false NX_ISOLATE_PLUGINS=false`; absolute paths from repo root; never touch user WIP files.
