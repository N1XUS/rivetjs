# i18n (design)

Goal: translations for SSR + CSR + resume with zero per-request cost for static messages, no catalog shipped to the browser, no hydration mismatch. Approach: compile-time inlining via a narrow compiler hook with a locale **variant** axis. One server build (per-locale static fragment arrays), per-locale client chunks.

References: [Paraglide strategy](https://paraglidejs.com/strategy), [Paraglide #88 (all locales per message)](https://github.com/opral/inlang-paraglide-js/issues/88), [Angular merge](https://angular.dev/guide/i18n/merge), [qwik-speak inline](https://github.com/robisim74/qwik-speak/blob/main/docs/inline.md), [next-intl precompile](https://next-intl.dev/blog/precompilation), [Lingui macros](https://lingui.dev/ref/macro), [next-intl routing](https://next-intl.dev/docs/routing/configuration), [Nuxt i18n SEO](https://i18n.nuxtjs.org/docs/guide/seo).

## Goals
- `t('cart.title')` in JSX → static text. Server: part of hoisted frozen fragment array, UTF-8 encoded once. Client: part of `spec.html`. No slot, no escape, no lookup.
- Params → primitive slots only (cheap `writeInteger`/`escapeText` path). Plural/select → per-locale switch over cached `Intl.PluralRules`.
- No catalog, ICU parser or message runtime in browser for static messages. No resume-state entries for messages.
- One server build serving all locales; one compile of source per module.
- Typed keys + params; typo = build error.
- Isomorphic, configurable locale resolution (url prefix, cookie, header/navigator, custom).
- Zero-cost rule: compiler output byte-identical when i18n not configured (ssr-bench Razor comparison unaffected).

## Non-goals (v1)
- Translations fetched at runtime (CMS/API) or changed without deploy.
- In-place reactive locale switch. Switch = navigation to other locale URL.
- Opaque dynamic keys (`t(var)`) — compile error.
- Source-text-as-key / auto-extraction (Lingui/wuchale style).
- MessageFormat 2 syntax.
- AI/TMS integrations; extraction to XLIFF/PO.

## Prior art: lessons applied
- Angular: per-locale output = true zero catalog; but N full rebuilds → avoid, compile once + variant emit.
- Paraglide: typed message fns, strategy array → adopt; all locales in each message fn (+ #88) → avoid, split per locale.
- qwik-speak / Qwik: inline on client, runtime on server → Rivet inlines on server too (fragment arrays).
- next-intl precompile: ICU → compact IR, plain strings untouched → adopt (IR at build only, lowered to code).
- Lingui/wuchale: rich text as indexed tags → adopt, lowered to JSX.
- Everyone: client reads locale from server output, never re-detects → adopt.
- Opaque keys unsupported everywhere with inlining (error or lost tree-shaking) → compile error + bounded escape hatches.

## Decisions
- Keys: explicit IDs (`cart.title`), nested JSON catalogs flattened with `.`.
- Syntax: ICU MessageFormat (plural, selectordinal, select, number/date args, `#`, tags `<b>..</b>`). Parsed at build only.
- Compiler hook: narrow, declarative static-call hook + variant axis (below). No general AST plugin API.
- Per-locale output: approach A (variant compile). Rejected: B (N full builds — build/memory ×N), C (server runtime lookup — per-request slot cost).
- Locale switch: full navigation (Paraglide/Qwik default); resumed state stays consistent.

## Packages
- `@rivetjs/compiler`: static-call hook + variants. No i18n knowledge.
- `@rivetjs/i18n` (new, `libs/i18n`):
  - `.` — `t` (typed, compile-time only marker; throws if reached uncompiled), `Locale` types.
  - `./vite` — plugin: loads catalogs, parses ICU → IR, registers hook table, emits `.d.ts`, wires per-locale client environments + manifests, HMR.
  - `./runtime` — tiny: `plural(locale, n)` / `ordinal` index, cached `Intl.NumberFormat`/`DateTimeFormat` by locale+options. Only imported by compiled code that needs it.
  - `./resolve` — strategy array, server (`Request`) + client (`location`/`document.cookie`/`navigator.languages`) adapters.
  - `./router` — `@rivetjs/router` integration: guard, `localizeHref`, alternate links.

## Config
```ts
rivet({
  i18n: {
    locales: ["en", "de", "es"],
    defaultLocale: "en",
    catalogs: "./locales/{locale}.json",   // or (locale) => object
    fallback: { "de-AT": "de" },           // chain → defaultLocale
    missing: "error",                      // "error" | "warn" | "fallback"
    routing: { prefix: "as-needed" },      // "always" | "as-needed" | "never"; map { en: "/us" } allowed
    strategy: ["url", "cookie", "preferredLanguage", "baseLocale"],
    cookie: { name: "rivet_locale", maxAge: undefined }, // session cookie by default
    timeZone: "UTC",
  },
});
```
- Build-time config only (serialisable). Custom strategies live in app code (`./resolve`), passed to router guard.

## Compiler hook
- `CompileOptions.staticCalls?: { id: string; module: string; export: string; prefixLookup?: boolean }[]`
  - Matches by **import binding** (`import { t } from "@rivetjs/i18n"`), not by name. Shadowing/re-export aliasing handled by binding resolution.
- `CompileOptions.variants?: { names: string[]; tables: Record<id, string /* registered table id */> }`
- Tables are **data, not callbacks** — no per-call JS↔wasm crossing. Registered once per build into wasm instance: `registerTable(id, json)`; updated on HMR.
- Table shape: `key → Variant[]` (index = variant), `Variant = string | Part[]`:
  - `{ t: string }` text, `{ a: name }` primitive arg, `{ n: name, f?: number-options }` number, `{ d: name, f? }` date,
  - `{ p: name, ord?: bool, cases: { "=0"?, one?, few?, many?, other: Part[] } }` plural (`#` → `{ n: name }`),
  - `{ s: name, cases: { [k]: Part[], other } }` select,
  - `{ tag: name, c: Part[] }` rich-text tag.
- Call shapes:
  - `t("k")` / `t("k", { …params })` literal key → resolved.
  - `` t(`k.${x}`) `` with `prefixLookup` → per-variant object of matching keys + lookup (`k.*`). Missing at runtime → `missing` policy value, dev warning.
  - anything else → diagnostic `error` (`t() key must be a string literal or a prefixed template literal`).
- Position handling:
  - JSX child text, attribute value → lowered into template static parts (text) + slots (args). Escaping by context (text vs attr) at compile time.
  - Rich-text tags → JSX elements: `t("terms", { link: (c) => <a href="/t">{c}</a> })`; tag without mapping → plain element only for allowlist (`b i em strong code br`), else error.
  - Non-JSX expression position (`aria`, `document.title = t(..)`, strings passed to props) → client: string literal / small concat fn; server: see variant emit.
- Unused hook → zero diagnostics, byte-identical output.

## Variant emit
- Server target (one module):
  - Template whose static parts differ per locale → fragment array becomes `Object.freeze([enFrags, deFrags, …])`; untouched templates unchanged.
  - Slot order may differ per locale (word order): slot values evaluated once in source order; per-variant write order table.
  - Render picks variant via render-root variant index (`renderToWriter(…, { variant })`, stored on request owner). Read once per template call; no context walk.
  - Variant index lives in `renderCore` closure (`RenderOptions.variant`), never module/global state → safe across concurrent requests and awaits.
  - Template fragments: hoist `_variants([frozen en, frozen de, …], orders | null)`; renderer picks `[variant]` in every fragment reader.
  - Per-locale runtime values (plural/select/number/date, non-JSX `t()`): `_variantValue([…per-locale thunks or strings])` record; renderer resolves by variant in child and attribute slots. `String(record)` throws ("translated value used outside JSX on server; use t.in(locale, …)").
  - After `await` (loaders/actions): `t.in(locale, "k", params)` (compiled to per-locale table + index of locale) — matches existing "no context after await" rule.
  - Modules with translated templates compile with server list-mount plans off (plans' flat fragments not variant-aware in v1).
  - Pre-encoding WeakMap keys per variant array → each locale encoded once per process.
- DOM target:
  - Modules referencing a registered call compiled once per variant; others compiled once, shared across locales.
  - Chunk output: `assets/<locale>/…` only for chunks containing translated modules; shared chunks emitted once.
  - Resume symbol ids identical across locales; one manifest per locale build (`client/<locale>/.vite/rivet-resume.json`). Browser never picks chunks: server embeds absolute chunk URLs from the manifest it is given (`state.c`), so router passes the request locale's manifest to `renderResumable`.
  - v1: one `vite build` invocation per locale (`RIVET_LOCALE=<l>`, `base` `/<assetsBase>/<locale>/`, outDir `client/<locale>`); repo has no Vite `environments` today. Shared chunks duplicated per locale in v1. Later (measured): shared-chunk dedupe + post-pass substitution à la `$localize translate`.
- Plurals: compiled code `[cases…][plural(locale, n)]`; locale constant per variant → `PluralRules` cached at module init.

## Locale resolution
- Strategy array, first hit wins: `url` (prefix per `routing`), `cookie`, `preferredLanguage` (Accept-Language / `navigator.languages`, best-fit match against `locales`), `baseLocale`, `custom-<name>`.
- Strategy = `{ server(req): Locale | undefined | Promise; client(): Locale | undefined }`. Client side sync only.
- Server: router layout guard → `event.locals.locale`, sets render variant, `<html lang dir>`, `Content-Language`, `Vary` only when cookie/header strategies can change response for same URL.
- Client in SSR/resume: **never resolves** — locale = `<html lang>`. Client `resolve()` used only by pure CSR / static `/` entry.
- Redirect only at root `/` (Nuxt `redirectOn: 'root'`); deep links/crawlers not bounced.
- Static hosting: prerender every locale (`entries()` × locales); `/` → tiny inline script redirect (cookie → navigator → default).
- `setLocale(l)`: writes cookie (if enabled), navigates to `localizeHref(currentPath, l)`.

## Router integration (`@rivetjs/router`)
- Optional segment `[[lang]]` already supported (`libs/router/build/routes.ts`) → `prefix: "as-needed"` maps to it; `always` → required `[lang]`.
- `i18nGuard(config, strategies)` → resolves, validates `params.lang` (unknown → 404), redirects at root.
- Head: `hreflang` alternates (+ `x-default`), canonical, `og:locale` + alternates via existing head links (`libs/router/shared/data.ts` `hreflang`). Requires `baseUrl`.
- `localizeHref(href, locale)` / `delocalizeHref(href)` for links + language switcher.
- Loaders/actions: `event.locals.locale` + `t.in(...)`.

## Formatting
- `{n, number}` / `{d, date, short}` → `Intl.NumberFormat`/`DateTimeFormat` cached by `locale + options` (process-wide on server, module-level on client).
- Time zone explicit: config `timeZone` or resolver output; server writes `timeZone` + render `now` into resume state only when a date arg used in a resumable binding — prevents server/client date mismatch.
- Startup check: Node full-icu (format `es` month); warn when small-icu.

## Types
- Plugin emits `rivet-i18n.d.ts`: `t` overloads per key; params typed from ICU (`number` for plural/number, `Date | number` for date, union for select cases, `(children) => JSX` for tags). Missing/extra param = TS error.
- Regenerated on catalog change (dev) and at build.

## Errors / missing translations
- Missing key in default locale → build error always.
- Missing key in other locale → `missing` policy: `error` (build fail, default for build), `warn` (dev default) + fallback chain value, `fallback` silent.
- ICU parse error → build error with catalog file:line.
- Param mismatch across locales (de uses `{count}`, en `{n}`) → build error.
- Uncompiled `t()` reached at runtime → throws with setup hint.

## Dev
- Catalog edit → re-register table, invalidate only modules importing changed keys (module → keys index from compile), HMR.
- `vite dev` serves all locales (variant per request) — no per-locale restart.

## Testing
- Compiler (`libs/compiler/tests`): hook off = byte-identical snapshots; literal / params / plural / select / tags / attribute / prefixLookup / opaque-key error / shadowed `t` not matched; per-variant slot order.
- `libs/i18n/tests` (`node --test`): ICU → IR, fallback chain, missing policy, d.ts generation, strategy resolution server + client adapters (fake `Request` / fake `location`).
- Runtime: server render per variant (each locale encoded once), plural cache.
- Browser (Playwright): resume in `de` loads only `assets/de/` chunks, no catalog bytes, no state entries for messages; locale switch navigation; no hydration/resume mismatch.
- Router: `[[lang]]` matching, root redirect, 404 unknown lang, hreflang output, static prerender × locales.

## Benchmarks
- ssr-bench: i18n lane with 3 locales vs Razor `IStringLocalizer`; target = no regression vs untranslated compiled lane (static text). Report per-locale req/s + memory.
- resume-bench: bytes per locale vs untranslated (expect ≈ equal; only i18n chunks differ).
- Build time vs locale count (1/3/10) — decides whether post-pass substitution needed.

## Implementation notes (fixes, 2026-10-03)
- Error pages: `ErrorInput.locals` carries the request's locals; `createApp` `i18n.resolve(request)` (`errorLocale(config)`) for unmatched URLs, then first path segment, then first locale.
- Redirects (supersedes "redirect only at root"): unprefixed URLs, root and deep links, 302 to the resolved locale's prefixed URL when it has one. Explicit choices never bounce: cookie naming the default locale (strategy order), same-site navigation (`Sec-Fetch-Site: same-origin`) under `as-needed`. `always`/prefix map: every unprefixed URL redirects. Prefixed URLs never redirect.
- Non-i18n SSR cost: module flag `translated` (set by `_variants` / `_variantValue`) gates every variant check in `visitValue` and `_variantOf`. Bench before the flag inconclusive (±3 % noise; per-row path +4 %), flag kept as strictly less work. Runtime server +39 B vs i18n merge; server-resume −413 B (checks constant-folded when no translated module is bundled).
- Dev per-locale client: router dev passes `i18n.locales` to `createApp` and a `devScripts(locale)` function; non-default locales load `entry.dev.tsx?rivet-locale=<l>`. i18n plugin `resolveId` (dev client only) keeps the query on app modules under the Vite root; `rivetCompileOptions(server, id)` picks the variant from it. Compiler plugin passes the module id to contributors. Production builds untouched (query only in `serve`).
- Tags inside plural/select cases: compiler lowers a case holding tags to a nested template (server `compiledTemplate` with hoisted frozen fragments; DOM `template()` spec); the plural/select helper returns it as the child value. Non-JSX value positions (variables, props, return values, resumed bindings) lower the whole message to a template when it has tags (top level or inside cases); attributes and `t.in` keep the diagnostic (strings; text says why).
- Locale cookie (2026-10-04): explicit choice = same-site document navigation (`Sec-Fetch-Site: same-origin`, `Sec-Fetch-Mode: navigate`, no `Sec-Purpose`) to a URL naming a locale other than cookie/headers pick → guard sets the cookie (`name`, `maxAge`, `Path=/`, `SameSite=Lax`, `Secure` on https, not HttpOnly). Never from Accept-Language alone; no rewrite when unchanged. `setLocale(locale, config)` writes the same cookie client-side, then navigates. Same-origin no-bounce kept as fallback when cookies are blocked. Router: any response writing a cookie via `event.cookies` gets `Cache-Control: private` (drops `public`/`s-maxage`, keeps the rest) once headers are final.
