## 2. Gaps

Format: **Gn — title** · severity · impact · competitor reference · approach (compiled, resumable, zero-cost-when-unused).

### Reactivity
- **R-1 Zombie child effects** · major · `batch(() => { v.set(null); show.set(false) })` runs the child effect reading `v()` before the parent disposes it → `null.x` crash in `{show() ? <p>{v()!.x}</p> : null}`; resumed/`clientEvent` handlers are always batched, so it surfaces after resume · Solid/Svelte run owners top-down · flush queue ordered by owner depth (or parent-first check before running a node); O(depth) only when >1 queued.
- **R-2 Lost effect errors** · minor · `flush` rethrows `errors[0]`, drops the rest · — · rethrow first, report others (`AggregateError` in dev, `reportError` in prod).
- **R-3 CSR handlers unbatched** · minor · same component behaves differently before/after resume (resumed `dispatch` batches) · Solid/Svelte batch events · wrap `bindEvent` listener in `batch`.
- **R-4 No stores / deep state / selectors** · major · nested state needs manual per-field signals; selection is O(n) · Solid `createStore`/`createSelector`, Svelte `$state` · separate entry, path signals created lazily, resume-serializable; `createSelector` O(1) per key.
- **R-5 No async derived / transitions / optimistic** · major · data fetch only via `<Async>`; no `isPending`, no optimistic values · Solid 2 async memos + `createOptimistic`, Angular `resource` · `asyncComputed` reusing `Async` machinery (pending/error signals); optimistic overlay signal reverted on settle.
- **R-6 Silent snapshot props** · major (DX) · `<Child n={n()}/>` never updates; no warning · Solid getters, Svelte runes · keep values-semantics (design: props are values, accessors explicit — like `For` rows, slot args, layout props); add dev-only diagnostic when a prop thunk reads signals.

### Component model / JSX
- **C-1 Spread props/attributes** · blocker · no prop forwarding, wrapper/headless components, `Link` passthrough · all competitors · components: merged-props object (`mergeProps`) built in compiled output; DOM: `spreadAttributes(el, () => obj)` reusing `bindAttribute` validation; server: filtered encode; resume records keys read. Emitted only where a spread appears.
- **C-2 Static component elements become resume regions** · blocker (perf goal) · `<Picture/>`, `<Link>`, `<Card title="x"/>` in a resume module become `SiteKind::Region` (`resume.rs` non-native child → region) → component code ships in the first handler chunk + per-render server bind closure; workaround = hoist call into a local · Qwik/Marko treat static subtrees as inert · no region when props/children have no calls/captures and the tag resolves to a statically known component; keep region for `clientOnly`/`lazyComponent`/dynamic tags; runtime safety net attributes stray reads to the enclosing region.
- **C-3 `style` banned; no class objects** · blocker · ordinary markup/ports fail; class objects stringify `[object Object]` · Svelte `style:`/`class:`, Vue/React objects · `style:prop={}` / `class:name={}` directives → DOM CSSOM `setProperty`/`classList` (CSP-safe), server escaped attribute with CSS value validation; static `class={{…}}`/`[...]` joined at compile time. `css``` (kit) already covers scoped sheets.
- **C-4 Closed event allowlist; no custom-element events/props** · major · `onPaste`, `onCopy`, `onTransitionEnd`, `onAnimation*`, `onToggle`, `onBeforeToggle`, `onClose`, `onCancel`, `onInvalid`, media, pointer over/out, custom events = compile errors; JSX types disagree with compiler list · all · extend list from lib.dom `GlobalEventHandlersEventMap`; `on:custom-name` namespace; `prop:x` element property; types generated from the same list. Unknown camelCase names stay errors (typo safety).
- **C-5 `<select value>` broken; `model:` limited** · major · SSR emits ignored `value` on `<select>`; DOM sets value before options exist · Svelte `bind:value`, Vue `v-model` · server: `selected` on matching option; DOM: apply after children; `model:value` on select/radio/number/range.
- **C-6 Conditionals re-create subtrees on every dependency change; no Show/Switch** · major · `{count() > 5 ? <A/> : null}` rebuilds `<A/>` (state loss) on each change while true · Solid `Show`/`Switch` · runtime `Show`/`Switch`/`Match` with memoized condition (lazy children); compiler auto-thunk of their children later. Changing ternary lowering itself alters every corpus case (oracle gate) → not now.
- **C-7 No Portal / Dynamic / object refs** · minor · modal/overlay and polymorphic `as` components need workarounds · React/Solid/Vue · `Portal` (DOM-only, SSR renders nothing / deferred), `Dynamic` component; callback refs suffice for refs.
- **C-8 No error boundaries** · major · one throw kills the page (DOM), truncates the stream (SSR) · all · reactivity owner error handler (`catchError`); runtime `ErrorBoundary({ fallback(err, reset) })` for DOM, server sync + `Async` rejection without own `error`, streamed segments; resume: boundary = region.
- **C-9 No raw-HTML sink** · minor · CMS/markdown need it · `innerHTML`/`{@html}` · branded `trustedHTML()` value (Trusted Types policy) accepted as child; never a string.

### SSR / resume
- **S-1 Error mid-stream truncates body** · major · see C-8 · boundaries · solved with C-8 (boundary fallback before flush; after flush: close open tags + error segment script).
- **S-2 Out-of-order streaming only in resume mode** · minor · non-resume apps stream in order · Solid/Marko · reuse segment protocol without state patches (template + swap script).
- **S-3 Dev never resumes** · major (DX) · resume/serialization/chunk bugs only show in production builds · Qwik/Marko dev = prod · dev SSR records with the resume recorder and reports serialization errors (cheap); full dev resume later.
- **S-4 Loader reload loop** · major · `import(url).catch(() => import(url))` retries a cached failed module record, then `location.reload()` → loop on a broken/CSP-blocked chunk · Qwik preloader · cache-busted retry (`?r=1`), reload at most once per URL per 10 s (sessionStorage guard).
- **S-5 Resumed element lookup O(document)** · minor · `querySelector` per element id · — · id map built during idle marker pairing.
- **S-6 Edge runtime** · major · no workers/serverless adapter; `loadBuild` uses `fs`; `server-resume` imports `node:async_hooks` · all meta-frameworks · `adapters/fetch` emitting `export default { fetch }` with inlined manifests; ALS via `nodejs_compat`/Deno/Bun.
- **S-7 No ISR/SWR/HTML ETag** · minor · cache via CDN headers only · Next/Nuxt/Astro.cache · `serverHeaders` already allows Cache-Control; add weak ETag/304 for HTML in node adapter (opt-in).
- **S-8 No SSR modulepreload / Early Hints** · minor · runtime/eager chunks discovered late · all · `<link rel=modulepreload>` for `eager` chunks + `Link` header (103 when adapter supports).

### Routing / data
- **N-1 Nested layouts remount; all layout loaders rerun** · major · state loss + wasted server work on sibling navigation · all · nested outlets with per-layout data signals (root-layout mechanism generalized); data endpoint `from=<layout id>` skips unchanged parents.
- **N-2 Guard/`onRequest` `Response` on data requests breaks client nav** · major · raw 302 → fetch follows → HTML → `decodeData` throws → "Something went wrong" · SvelteKit/RR JSON redirect envelope · `wantsJSON` → 3xx → `{redirect}`, other → `{reload:true}`; client `location.assign`.
- **N-3 No public nav/search-param API** · major · forms fake navigation via synthetic anchor click · `goto`, `useNavigate`, `useSearchParams` · resumable `navigate()`/`invalidate()` dispatching through the delegated router; `useParams()`/`useSearchParams()` accessors.
- **N-4 Revalidation model** · major · no `depends`/`invalidate`/`shouldRevalidate`; prefetch cache (5 s) never invalidated after a mutation · SvelteKit, RR · clear prefetch map on submit/action; `invalidate()` from N-3; `depends(key)` later.
- **N-5 Single-flight mutation** · major · enhanced action response carries only the result · Solid/SvelteKit/Next · action response = `{action, data, head}` after same-URL revalidation (batch-1 is fixing same-URL revalidation; build on it).
- **N-6 Deferred loader data** · major · slow loader blocks TTFB · RR/SvelteKit streamed promises · `defer({slow: promise})` → streamed `Async` segment via existing patch protocol.
- **N-7 Hash-only / query-only navigation reruns the route; forward nav loses scroll** · minor · refetch + remount on `#x`; `go()` overwrites `history.state` · all · compare path+search; save scroll on every `popstate`; preserve app history state.
- **N-8 Error pages drop layouts** · minor · `_error` renders without site chrome · Next/SvelteKit · render `_error` inside nearest layouts whose loaders succeeded.
- **N-9 Action name with query** · minor · `?/save&next=/b` → 404 · — · split action name at `&`.
- **N-10 Route announcer / scroll restoration** · major (a11y) · screen readers get no navigation announcement; browser auto-restore fights manual restore · SvelteKit/Next/Nuxt announcer · one visually hidden `aria-live="assertive"` node updated with `document.title` after commit; `history.scrollRestoration = "manual"`.
- **N-11 Server functions** · major · RPC needs a route/endpoint file · Next/Solid `"use server"`, Qwik `server$`, SvelteKit remote functions · compiled `serverFn` export: DOM stub posting to `/_rivet/fn/<id>`, args via `resume-format`, origin check, schema validator hook; emitted only when used. Needs a design spec (decision).
- **N-12 Parallel/intercepting routes, param matchers** · minor · modals-as-routes · Next · defer (low demand vs complexity).

### Security
- **X-1 CSRF model holes** · major · behind TLS proxy every action 403 (`url.origin` is `http://host`); POST without `Origin`/`Sec-Fetch-Site` accepted; page `onPost`/`onPut`/`onDelete` run before the check; endpoints unchecked · SvelteKit `checkOrigin`, Next Server Actions, Blazor antiforgery · node adapter `origin` / `trustProxy` options; origin check for every unsafe method before any handler (page routes; endpoints opt-out `export const csrf = false`); form content types without origin headers rejected.
- **X-2 Open redirect** · major · `redirect("https://evil")`/`//evil` pass · — · same-origin by default; `redirect(url, { external: true })` for absolute; reject `//`, `\`.
- **X-3 No body limit for actions/endpoints** · major · unbounded request streaming (30 s timeout only) · Blazor/Kestrel defaults · handler `maxBody` (1 MiB default, 413), applied to `request.formData()/json()/text()` reads.
- **X-4 URL sanitization** · major · SVG `<animate attributeName="href" values="javascript:…">` and `<object data>` unchecked; unsafe dynamic URL throws → SSR 500 (DoS-ish); `data:image/*` blocked on `<img>` · React/Angular sanitizer · neutralize to `about:invalid#rivet` (+ dev warning) instead of throwing; allow `data:image|video|audio/*` (not svg+xml) on media `src`; extend URL attribute set (`object[data]`, `a[ping]`, SVG animation `values/to/from/by` when `attributeName` is href-like).

### DX / tooling
- **D-1 Parse errors lack position** · minor · Vite shows `x.tsx:1:1` · all · pass oxc span through diagnostics.
- **D-2 No server-error overlay / dev 404** · minor · server render errors show a message only · Next/Nuxt overlay · send Vite `ws` `error` payload with stack; dev 404 lists routes.
- **D-3 No public testing utilities** · major (adoption) · users can't unit-test components · RTL, `@solidjs/testing-library`, RR `createRoutesStub` · `@rivetjs/runtime/testing`: `render()` (DOM target, auto-dispose), `renderToString` helper, `flush()`, `fireEvent` via batch, fake router; zero cost (separate entry).
- **D-4 JSX types gaps** · minor · excess-property errors on valid attrs (`popover`, `inputMode`, `fetchPriority`, `<meta charset>`), custom elements need augmentation · all · catch-all for `data-*`/`aria-*`, generated attr lists, custom element fallback.
- **D-5 Component context in runtime errors** · minor · "Unsafe URL attribute", "Unsupported DOM child value" carry no component/attr name · — · `#dev` adds component + attribute names.

### Blocked out-of-scope items
- forms: fake navigation (N-3), same-URL revalidation (N-5, batch-1), `safeRedirect` duplicated (X-2).
- kit/images: `<Picture/>` region shipping (C-2).
- devtools: props snapshot confusion (R-6).

## 3. Things Rivet already does better (keep)
- SSR throughput: beats Razor on CPU/page, p50, p99, TTFB and peak memory at 5k rows; byte-level emit, list tapes, server list mounts.
- Resumability: per-binding granularity (text/attr/region/model/ref/effect), no component re-execution in the browser (Playwright-checked), 1.7 KB loader, 14.4 KB JS before input vs Qwik 39.6 KB, 1.1 ms first click vs Qwik 17 ms; row adoption of server `For` rows; dependency prefetch so the first interaction updates synchronously across chunks; Save-Data / scroll-guarded scheduling.
- Out-of-order streaming integrated with resume state patches (index-aligned), continuation on failure/deadline/cut stream.
- Compiled named + scoped slots (lazy, zero runtime cost) — richer than React/Solid children.
- `model:` two-way binding with IME handling and zero app chunk on resume.
- Security posture by default: strict nonce CSP, opt-in Trusted Types, CSSOM-only view transitions, attribute-name bans, server-only import guard (`*.server.*`, `node:*`), secure cookie defaults, 5xx digests.
- In-file server code with byte-position-preserving removal (source maps and symbol ids match across targets).
- Typed `Link to`, `PageProps<typeof serverLoad>` with a serializability type check.
- Zero-cost dev diagnostics via `#dev` condition; production bundles carry none.
- HMR that keeps signal state by creation order.
- View transitions with CSP-safe naming, pending UI timing (`delay`/`minDuration`), events.

## 4. Trade-offs kept (gaps not pursued)
- Getter/reactive props (Solid model): changes every component call's compiled output (oracle gate, all lanes' DOM output) and adds per-prop getter cost; Rivet's explicit-accessor convention (rows, slot args, layout props) is consistent. Keep values; add the R-6 dev diagnostic. Open question for the user.
- Memoized ternary lowering in the compiler: same reason (alters every conditional's output); `Show` covers it opt-in.
- Proxy-based deep stores: conflict with resume serialization of identity + zero-cost; any store must be compiled/path-signal based (R-4, deferred).
- Hydration fallback for non-resume modules: would reintroduce re-execution; instead improve diagnostics (S-3).
- Parallel/intercepting routes: low value per complexity now.
