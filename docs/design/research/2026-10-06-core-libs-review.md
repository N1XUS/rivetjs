# Core libs review — compiler, devtools, reactivity, router, runtime (2026-10-06)

Read-only review of five libs across five axes: server perf, client perf, API standardization, DX/adoption, build/serve diagnostics. Every item cites code; measured numbers come from scratch probes on this checkout (Node 26, M-series). Nothing was changed.

## Cross-cutting findings (the themes behind most items)

1. **v1/v2 DOM duality is the root of most client perf and DX losses.** v2 (`_tpl`/`_insert`/`_for`) is active only when `!server && !resumed && !dev && !i18n` (`libs/compiler/rust/src/compile/dom_v2.rs:143`). So: resumed pages (Rivet's flagship), dev server, tests, and any i18n app ship the slow v1 ABI. Any `<select>`/`<option>`/`<textarea>`/`<title>`/`model:`/`prop:`/`preload=` anywhere in a native tree silently drops the **whole root** to v1 (`dom_v2.rs:147-230`). Show/Switch/Async/Router are v1-only, so one `<Show>` pulls +2.2 kB brotli, `Router` +2.8 kB — this is the krausest size LOSE (5.79 vs Solid 4.50 kB).
2. **Dev ≠ prod.** Dev and the testing register compile v1; prod compiles v2 (`libs/compiler/vite.ts:631`, `libs/runtime/testing-register.ts:34-38`). Known behaviour deltas (empty class removal, delegated event order, untracked imperative DOM). The dev reactivity façade also masks the unbound-`set` footgun: works in dev+devtools, throws in prod (`libs/reactivity/dev.ts:92`). Resumed pages bypass dev diagnostics/a11y entirely (`dom-resume.ts:7` imports `./dom.ts` directly).
3. **Silent fallbacks everywhere, no diagnostic taxonomy.** Compiler codes are assigned by message-prefix matching (`rust/src/diagnostics.rs:7-52`), so many messages fall to RV9000; `compile()` output carries no code at all (only `check` does), so the Vite overlay never shows `RVxxxx`; `check` can't see css``/i18n/server-split errors; router/runtime/i18n use five different prefixes. No warning tier exists in the compiler.
4. **Internals leak into public surfaces.** 16 `_`-prefixed reactivity exports, ~20 v1+v2 ABI names on `/dom`, ~25 unprefixed router internals on `/client`, `_debug`/`_inspect` as the only graph API.
5. **Per-request allocation debt on the server** sits outside the ssr-bench lane: router is never benchmarked (`apps/ssr-bench` doesn't import `@rivetjs/router`), and server `<For>` isn't exercised (lane uses `.map`).

## 5. Build / serve diagnostics

**Today:** compiler = ~55 error families, codes by message-prefix classifier (many → RV9000: slot errors, `Invalid style property`, css``, `Message tag` singular/plural mismatch); `compile()` returns no code, Vite `fail()` joins all messages with first loc only, never `this.warn`; `check` lacks `styles`/`staticCalls`/`serverExports` so css``, RV4001–4005 and server-split errors are editor-invisible; RV2101/RV3101 editor-only; router scanner/plugin only `throw` (no codes, no warnings); runtime `DEV.hint` keys without codes/URLs; prod messages bare English; five prefix styles (`Rivet:`, `[rivet]`, `[rivet i18n]`, `rivet router:`, `rivet check:`); i18n plugin uses `console.warn` not Vite logger; `import("@rivetjs/devtools/server").catch(()=>null)` swallows real errors.

**Proposal (High / M):** one registry (`libs/language-core/codes.ts` or JSON shared with Rust): `{code, severity: error|warning|info, title, docs: https://…/e/RVnnnn, fixable}`. Codes assigned at emission sites (`compile/*` modules, `compile.rs` untouched). `compile` and `check` share one shape; `fail()` sets `RollupError.code`/`.url`; runtime hints → RV5xxx with URL in dev, code+short URL in prod (saves bytes); Errors tab groups by code; CLI `--format json`.

Ranges: RV1 syntax/JSX/safety · RV2 resume/serializability · RV3 imports/helpers/routes · RV4 i18n · RV5 styles · RV6 slots · RV7 config/plugin options · RV8 perf hints (info) · RV9 internal. Router needs its own block (agent proposed RV2001–2010; collides with resume range → use RV3xxx or a new RV6/7 slot).

**Missing diagnostics, all verified absent:**
- Module-level / imported function passed as prop to resume component; JSX content prop; plain children of cdk overlays (fail only at SSR serialization) — **High**
- `.ts` importing `@rivetjs/runtime/dom` (silent SSR bundle of dom.ts) — Med
- v2→v1 fallback (select/model:/i18n/preload), list mounts off (resume/i18n), eager `fallback` — perf-hint tier — Med
- Effect/computed created with no owner (leak); effect returning fn/Promise; unbound `signal.set`; circular/non-settling errors don't name node — Med
