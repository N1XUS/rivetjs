# docs/ — internal documentation index

> **Keep this file current:** ALWAYS update this CLAUDE.md in the same change whenever code in this directory changes (APIs, layout, commands, invariants, gotchas).

Internal, contributor-facing docs (user-facing docs live in `apps/docs/content` and `apps/cdk-docs/content`). Three folders; nothing at the root except this index.

## Layout

- `guides/` — how a feature works + its rules (one per subsystem; linked from the lib CLAUDE.md files).
- `design/` — design records: `specs/` (approved designs, `YYYY-MM-DD-<topic>-design.md`), `plans/` (implementation plans), `research/`, plus standalone implementation notes.
- `benchmarks/` — measured comparisons (`*.md`) with their raw `*-summary.json` / `*-diagnostic.json` next to them; `direct-ssr/` = archived direct-SSR experiments (sources removed after commit `876929e`; the `experimentalServerDirect` option, its runtime protocol and design docs removed 2026-10-07).
