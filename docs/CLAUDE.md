Internal, contributor-facing docs (user-facing docs live in `apps/docs/content` and `apps/cdk-docs/content`). Four folders; nothing at the root except this index.

## Layout

- `guides/` — how a feature works + its rules (one per subsystem; linked from the lib CLAUDE.md files).
- `design/` — design records: `specs/` (approved designs, `YYYY-MM-DD-<topic>-design.md`), `plans/` (implementation plans), `research/`, plus standalone implementation notes.
- `blog/` — public write-ups: `dev-to/` = the dev.to post (`react-inside-rivet.md` with dev.to front matter; replaced the 3-part series 2026-10-18, `gists/` = snippet sources mirrored as secret gists + `urls.txt`, `images/` = `prompts.md` + `generate.sh` (codex headless image generation) + PNGs, `README.md` = publishing steps). Not built by any site; numbers are quoted from `benchmarks/`.
- Latest chart sources: `benchmarks/2026-10-23-ssr-comparison.{md,json}` (+ `.notes.md`) for Docker SSR and `benchmarks/2026-10-23-krausest.{md,json}` for local keyed-table measurements; docs retain the older mount / resume run dates and reject published krausest framework rankings across Chrome major versions.
- `benchmarks/` — measured comparisons (`*.md`) with their raw `*-summary.json` / `*-diagnostic.json` next to them; `direct-ssr/` = archived direct-SSR experiments (sources removed after commit `876929e`; the `experimentalServerDirect` option, its runtime protocol and design docs removed 2026-10-07).
