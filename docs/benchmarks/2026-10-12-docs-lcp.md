# Docs sites LCP floor (lane DOCS-LCP, 2026-10-12)

Goal: home `/` LCP ≤ 1052 ms (Astro editorial article, `2026-10-11-editorial.md`), every docs page faster.

## Method
- Built `apps/docs` (`node libs/docs-kit/cli.ts build apps/docs --dist apps/docs/.artifacts/<variant>`), served by `apps/editorial-bench/harness/static-server.mjs` (gzip).
- Lighthouse mobile (default config: simulated slow 4G 150 ms RTT / 1.6 Mbit/s, 4× CPU, Moto G Power), median of 3, under the bench lock (maxLoad 8; load at acquire noted). Pages: `/` and `/learn/resuming/` (content page).
- Lantern (simulated) LCP counts every non-image request that finished before the observed (unthrottled) LCP, low-priority ones included: on a local run fonts, stylesheets and `<link rel=modulepreload fetchpriority=low>` all finish before the first paint, so their bytes are on the LCP path even when the browser does not wait for them.

1. Fonts: Geist + Geist Mono apply only under `<html data-fonts>` (theme.css), set by the shell script after the first contentful paint (paint observer → task) or before it when `localStorage["rivet-docs-fonts"]` is set (an earlier page loaded them). Text paints in the metric-matched fallback faces first, then the faces swap in. Subsetting Geist (29.7 KB latin) needs a font subsetter (harfbuzz) that is not a repo dependency: not done; with the fonts off the first-paint path it would only help the swap.

2. ## Fix round (review 2026-10-12)
- Later page of a visit (flag set, warm HTTP cache; `/assets/*` immutable as in `_headers`), Playwright 150 ms RTT / 1.6 Mbit/s + 4× CPU, `/learn/resuming/` → `/reference/config/`, 412 + 1350 px: faces `loaded` at the first paint, CLS 0, LCP 280–300 ms, both `swap` and `optional`. Without immutable caching (revalidation): faces still loading at the first paint, CLS 0.0001 (1350 px). Faces now `font-display: optional` (no late swap even with an evicted cache); no preload needed.
- Lighthouse later page (same Chrome profile, storage kept: `/learn/resuming/` first): `/reference/config/` 99 · FCP 811 · LCP 811, `/` 100 · FCP 785 · LCP 801, CLS 0. Cold (median of 3): `/` 100 · FCP 808 · LCP 1052, `/learn/resuming/` 100 · FCP 1053 · LCP 1804.
- Client-added DOM: `CLIENT_SELECTORS` (shell theme menu + mobile drawer, cdk overlay layer + interaction attributes, kit `<Transition>` attributes, docs-kit highlighter / copy / chart DOM) + per-site `criticalCss.extraSelectors`; the shell also turns the full sheets on at the first pointerover / touchstart. `apps/docs/tests/critical-css.test.ts` opens the theme menu and the mobile drawer with the full sheets blocked: equal computed styles (before: the theme menu was unstyled). Inline: `/learn/resuming/` 8.5 → 9.1 KB gz, `/reference/config/` 8.6 KB gz, `/` 11.1 KB gz; cdk-docs ≈ 33 KB raw / ui-docs ≈ 74 KB raw per page.
- Guards: pages without the activation script or without a plain head stylesheet link keep their links (build log `critical css: kept stylesheet links of …`; none in the three sites); head links in any attribute order; links with more attributes (`media`, …) stay render-blocking. Named `@layer x{}` blocks are kept empty so the layer order never depends on which rules were used.
