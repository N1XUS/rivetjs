## What changed

1. **Fetch-ahead.**
   - The manifest gains `deps`.
   - The tail gains `data-fo`.
   - The loader appends low-priority modulepreloads after `load`, which costs +79 B br.
2. **Adopt O(touched).**
   - Form controls come from the alignment map.
   - `opener` is incremental, and ATTR records are looked up by `querySelector`.
   - Runs are paired by kind, so nodes no longer move and the rows below are not relaid out.
   - A list adopts in O(1) through a keep token. A sole list is not scanned until needed, and rows and the client `_for` are built on first need.
3. **Keyed row writers.** A keyed read made only through hoisted bindings whose captures every row supplies reruns those bindings over the lazy rows.
4. **Cold press.**
   - dom-resume's replay is ported: focus-back, UNDO-FOCUS, COLD-FOCUS hide, retarget, and the listeners a replay attaches.
   - The default `data-events` gains the pointer, mouse and focus events, and the held state records the focused element (+38 B br).
   - Synthetic enter events reach the units that the first mouse event adopted.
5. **Collection hosts.**
   - UNKEYED records adopt.
   - Build passes run outside every unit.

### What changed

- Holes under providers: `_rB` puts a `CURRENT` frame naming the boundary on the current owner's context while its body runs, so a children slot rendered later under an owner the body made (a `Provider`) keys its `Async`s by that boundary, as the browser counts them.
- Settled values that are not JSON data (a deferred loader's `Date`) ship as their resume table (`a` entry settled 2) and decode with the router `Root`'s decoder; the content adopts instead of rendering again with a `{}` deferred handle.
- Shell cache: fill, H-holes hit, H-replay, full replay and the frame watch on derived documents (router `shell-app` / `deferred-app` on a derived build, cdk fuzz shell routes).
- `Suspense`: a unit whose probe run suspends one renders in the browser (was a resume error and a reload); unmounting a `Suspense` while a load below it is pending no longer throws (both models).
- Cold hover: synthetic enters in the browser's order.

## C4 / C5: collection hosts adopt after the first input (DERIVED-C4 / C5, 2026-10-22)

Lane DERIVED-C4 built server dependency facts and deferred adopt but did not get them green. Lane DERIVED-C5 fixed the test, found and fixed two adopt bugs, cut the facts' server cost and measured the result on the LVD-2 story harness ([lazy rows vs derived](2026-10-21-lazy-vs-derived.md)).

- **What it does.** The derived build sends `@rivetjs/reactivity` of app and library code (not the runtime's own) through a derived alias. The server then knows which component made and read every signal, also plain ones from `.ts` helpers (cdk `createListData`, collection state). A heavy dependent component (≥ 8 reactive sources in its subtree) whose reads are all named in the wake lists is flagged `DEFER`. The browser claims it with its parent but adopts it later: on its own first event, before a write it depends on, on a form submit that contains it, or at idle.
- **Not deferred:** a component whose signal is read outside it, one that writes a signal made outside it, one rendering a `Router` level (`_rEager`), and every component of a render holding a store, a shell cache render or a stream with a pending `Async`.

### Bugs found by the C5 tests and fuzz

- **Cyclic wake lists overflowed the stack.** An ancestor that reads a keyed signal its descendant made has the descendant as a source, and the descendant's parent is the ancestor. `need` recursed between them until the stack overflowed, and the page reloaded. This happens on base derived too (C4's test fixture hit it with a helper keyed in the page module). `need` now guards re-entry.
- **A deferred field missed the form's `invalid` event** (fuzz `/checkbox`, shard 2). A submit click validates every control of the form, but `invalid` is not a delegated type, so the deferred CheckboxField had no listener yet. Deferred units inside a form now adopt before its submit or reset runs (both the live path and the cold replay).
- **The C4 test expected unkeyed signals from a page-module helper,** but the compiler keys them (`_rSig`). The fixture now imports its helper from a `.ts` module, as cdk does.
