### T7 (history): bytes and requests before input (the loss vs Astro, fixed by T7b)

The bridge lane's 16 requests before input, as measured with Playwright on the built lane:

| group | requests | raw bytes |
| --- | ---: | ---: |
| React vendor (`client-*.js`; Astro ships the same React) | 1 | 221 KB |
| Rivet resume runtime: `resume-entry`, `reactivity`, two `dom-*` chunks, `resume-loader`, `preload-helper` | 6 | ≈ 53 KB |
| bridge driver `client--*.js` | 1 | 2.3 KB |
| facades `*.react.tsx-*` (counter, picker) | 2 | 1.1 KB |
| island modules `Counter.react-*` / `Picker.react-*` / `Chart.react-*` | 3 | 1.8 KB |
| `resume-_hydratedRoot`, `resume-Counter`, `resume-Picker` | 3 | 0.9 KB |

- Cause: the island hydration is a Rivet `clientEffect` (`libs/bridge/root.tsx` `_hydratedRoot`), so it boots the full resume runtime. That happens even on a page with no Rivet resumable: `rivet-native`, the same page in Rivet, ships 0 JS before input.
- The chunks are not grouped either: one chunk per facade, island and resume symbol.
- Fix planned as T7b (plan "Task T7b: islands-only lean client"):
  - routes without Rivet resumables boot with the bridge driver, the adapter and the framework vendor only;
  - the cold path is grouped into ≤ 3 JS requests.
- Next's 164 KB (gzip est.) holds the React runtime plus the RSC payload, which repeats the 1000 rows inline (HTML 373 KB vs 113 KB).

### rivet-native under Fast 3G (T7 numbers; same in the T7b run)

- First input → paint over Fast 3G + 4× CPU: rivet-native takes 1.43 s (counter), 0.53 s (picker) and 1.16 s (chart). The React lanes take 16–57 ms.
- Cause: a resumed page loads nothing before input, so the first click fetches the loader, the runtime and the handler chunks over a 562 ms RTT link. The React lanes already hydrated during load or idle.
- Unthrottled, the same click takes 32–33 ms.
- This is a Rivet resume preload-planner gap, not a bridge one. Prefetching the handler chunks of visible interactive content on idle would close it.
- The "Island cost" list reads rivet-native's Fast 3G paint as a bridge WIN for that reason.
