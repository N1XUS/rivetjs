## M2 gate: derived model vs serialized (lane M2-GATE, 2026-10-20)

- Base `543da6a73` (M2-C3), snapshot build. Lanes: `rivet-resume` (serialized, default build) vs `rivet-derived` (same `router-app`, `rivetRouter({ resume: { model: "derived" } })`, `vite.derived.config.ts`), both on `/resume`; Razor (`dotnet`, `/page`, static peer) for scale only.
- Host: macOS arm64, 14 cores (Docker 29.1.2, 10 vCPU VM), other non-Rivet containers running; 1-min load 3.9–7.0 during trials (all < 8). Tuned GC, node generator, 1 CPU / 512 MiB per lane.
- Not like-for-like on data: the derived build ships lazy rows by design and keeps row values out of the tail (read back from the DOM); `rivet-resume` is the default build (lazy rows off). The derived lane is **interaction-broken** (below), so its server numbers lack whatever the router integration (R5) will add.

### Reading

- Server: derived wins at 5000 rows (CPU/page −18 % c1, −20 % c10; p50 −14 % / −18 %; peak RSS −38 % / −11 %), ties at 100 rows, **loses at 1000 rows c1** (CPU/page +13 % run 1, +6 % run 2; TTFB p50 +0.35 / +0.27 ms) and is within noise at 1000 c10. Peak RSS is lower in every cell (−11…−38 %).
- `renderDerived` wraps `renderResumable` (`libs/runtime/server-derived.ts`): the serialized recorder still runs under the derived one, so mid-size pages pay both. A dedicated derived server path is the expected CPU / TTFB fix.
- Bytes: derived HTML −10…−14 % raw, −40…−51 % brotli (no state table); JS before input 36 KB → 0.
- Commands: see `apps/ssr-bench/CLAUDE.md` / README `rivet-derived`; this run: `RIVET_BENCH_NODE_IMAGE=rivet-ssr-bench-node:m2gate SSR_BENCH_PROJECT=rivet-m2gate SSR_BENCH_PORT_PREFIX=183 python3.12 apps/ssr-bench/benchmark.py --skip-build --frameworks rivet-resume,rivet-derived,dotnet --rows 100,1000,5000 --concurrency 1,10 --duration 10 --warmup 3 --repeats 3` (image built with `docker compose -p rivet-m2gate -f apps/ssr-bench/compose.yaml --profile variants build rivet-derived`), probe `node apps/ssr-bench/spikes/derived/probe.ts --lane rivet-resume=http://127.0.0.1:18315 --samples 10` and `--lane rivet-derived=http://127.0.0.1:18332 --samples 3`.
