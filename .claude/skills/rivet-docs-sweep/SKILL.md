# Rivet docs sweep ("docs follow code")

Stale description = incomplete change. CI checks generated outputs with `--check`.

## 1. Find every mention

Grep the OLD name / behaviour / value / path (not just the new one):

```bash
grep -rn --include='*.md' --include='*.ts' --include='*.tsx' --include='*.json' -e '<old>' \
  libs apps templates skills docs scripts CLAUDE.md README.md CONTRIBUTING.md \
  --exclude-dir=node_modules --exclude-dir=dist --exclude-dir=.rivet
```

Places that describe behaviour:
- nearest `CLAUDE.md` + root `CLAUDE.md` (repo map, rules, gotchas);
- user docs `apps/*/content/**`, examples `apps/*/examples/**`;
- `templates/**` (AGENTS.md / CLAUDE.md) and `libs/create-rivet`;
- `libs/mcp/ai/**` (source of `skills/`, Cursor / Copilot rules, starter AI files);
- `docs/guides/**`, specs stating current behaviour, JSDoc, READMEs;
- compiler diagnostics `libs/compiler/codes.json`, `libs/language-core/explain.json`.

## 2. Regenerate (never hand-edit `Generated by … Do not edit.` files)

- `node libs/mcp/ai/sync.ts` → skills / editor rules / starter AI files.
- `node libs/mcp/build-data.ts` → MCP data.
- `node libs/docs-kit/cli.ts errors apps/docs` → `/errors/RVxxxx` pages.
- llms.txt / llms-full.txt / per-page `.md` come from the docs build; check with `llms <app> --check`.
- Docs routes: `nx run <app>:typecheck` regenerates them.

## 3. Check

`check-content <app> --strict`, `check-snippets <app>`, `llms <app> --check`, `errors apps/docs --check`, `build-data.ts --check`, `sync.ts --check`. Re-grep the old term: zero hits outside history / changelog.

Upstream names (React Aria, HeroUI) may be mentioned (user ruling 2026-10-27). Icons: lucide only, never invented SVG paths or UTF glyphs.
